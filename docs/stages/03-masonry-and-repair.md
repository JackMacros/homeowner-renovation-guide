# 03 砌墙、门洞与基层修补

[上一阶段：拆除与清运](02-demolition.md) · [返回整体流程](../00-process-overview.md) · [下一阶段：门窗、空调、新风等前置工程](04-windows-and-hvac.md)

[打开本阶段一页式现场清单](../checklists/03-masonry-and-repair.md)

## 阶段目标：新墙位置、洞口和后续接口都能复尺

按已确认的图纸新建非承重隔墙、修整门洞和拆除边缘，并完成后续工序需要的预埋/加固交接。验收时要同时核对墙的位置、厚度、洞口和隐蔽连接，不只看“墙立起来了”。

本阶段不授权改动梁、柱、楼板、剪力墙、承重墙或既有结构洞口；不确定的结构问题先停工请设计/结构专业人员核实。家庭装修中的“新砌一面轻墙”也不能只凭工人经验确定位置、厚度、过梁和连接方式。

## 进场条件：先把完成面和设备尺寸算进去

- 02阶段已完成拆后复尺，墙位、门洞和保留部位已经更新到当前版图纸；
- 每面新墙有编号，标明起止点、长度、高度、墙体系统、厚度和两侧完成面；
- 门、柜体、洁具、开关插座、空调/新风、管井和检修口的位置已协调；
- 电视、吊柜、洗手台、热水器、扶手等重物位置和预期固定方式已交给做墙的工人；
- 楼板能否承受拟新增墙体重量已按设计/房屋资料确认；重墙或位置、荷载有疑问时先咨询结构专业人员；
- 若有设计规定的拉结、构造柱、过梁、顶部连接或防潮节点，现场有可读图纸/节点；不能让工人临时“按常规”补一个尺寸。

尺寸要分清三个面：结构/砌块面、抹灰完成面、瓷砖/门套等最终完成面。比如橱柜净宽、门洞宽和走道宽，应从预计完成面反算，不能只量砖墙毛坯面。每处写清卷尺从哪里量到哪里。

## 工作范围：这阶段做什么，什么留到后面

本阶段通常包含：新建非承重隔墙；墙体与主体/相邻墙按设计连接；门洞过梁或配套门洞构造；预埋重物加固；封补拆除遗留的非结构洞口；修整基层至下道施工可接续。

本阶段不宜抢做：水电开槽后的槽口修补（放在05水电完成后、06封槽与基层处理）；最终墙面找平、腻子和涂料（放在10）；卫生间防水（07）。卫生间新墙的砌体/基层处理不能替代防水，防水高度、墙体类型和穿管节点按07章与设计确定。

门洞不能擅自开进梁、柱、剪力墙或承重墙。新开洞口若靠近结构边、跨度较大或改变既有结构，应暂停该处，取得设计/结构专业意见及应办手续后再做。

## 新墙怎么选：先按图纸和使用要求，再比较单价

| 墙体系统 | 常见规格/构造线索 | 优点 | 主要限制与适用提醒 |
| --- | --- | --- | --- |
| 蒸压加气混凝土砌块（AAC） | 市场常见长度约600mm、高度约200mm，厚度常见100、120、150、200mm等；各厂尺寸、强度/干密度等级不同，以订单和设计为准 | 可现场切割，常见于室内非承重隔墙，管线开槽相对方便 | 块体易崩角、含水状态和粘结砂浆很重要；墙体较厚/较高、挂重物、门洞及湿区需按设计加强；不能仅凭“轻”认定楼板绝对可承受 |
| 混凝土小型空心砌块等砌块墙 | 规格、孔型和强度等级按设计；不同孔型对拉结、灌芯、挂件和开槽做法不同 | 局部承载与固定方式可能较灵活，适合设计指定系统 | 不能把孔洞当成随便填砂浆；不得现场擅自灌芯、切断肋壁或打穿；须用相配套的砌筑砂浆和连接细节 |
| 轻质条板/装配式墙板 | 常见厚度依产品系统而异；板宽、企口、钢卡/连接件及门洞配套需查该厂系统图 | 现场湿作业可能较少，施工较快，墙厚可控 | 依赖系统连接、板缝和门洞节点；开槽、吊挂、拼缝修补不能照搬砌块墙；确认单块重量、搬运条件及板材允许吊挂荷载 |

这些是市场常见规格线索，不是推荐你固定采用某一厚度。具体要让设计/设备/门厂按墙体用途、隔声、防火、湿区、管线和承载要求给出墙体系统。轻钢龙骨石膏板隔墙属于另一套骨架墙系统，龙骨间距、板层、填充、门框和挂重加固应作为完整系统另行确认，不拿砌块墙标准验收。

### 价格怎么比，避免“每块便宜、到场更贵”

砌块和条板的成交价受江苏具体城市、工厂距离、订货量、楼层搬运、是否含税、卸货/上楼和退补货影响。不同城市、不同规格的报价不能拼成一个“江苏统一价”。可先用南京信息价作工程计价参照：2026年7月，蒸压砂加气混凝土砌块 A5.0、B06 标注为 **300.69元/m³（税前综合信息价）**；该信息价说明其为计价参考，不是政府定价，也不是家庭零售成交承诺。它不等于你实际送到户的含税价；询价时另核实际税率、起订量、运输/卸货、上楼、破损补货及是否按整托销售。不同强度/干密度等级、产品来源和交付条件不能直接拿这个数比价。[南京市2026年7月建设工程材料信息价](https://zjcku.com/pricefilede.aspx?fileid=9f8aef49b9f1d127749f80968baffd83)

签单前仍让本地至少三家按同一张清单报价，并记录：

| 报价字段 | 必须问清 |
| --- | --- |
| 产品 | 生产企业、实际工厂地址、完整产品名、标准号、厚度/规格、强度及干密度等级（该产品有标注时） |
| 计价单位 | 元/块、元/m³还是元/㎡；按块报价的计量尺寸与折算方式 |
| 到场服务 | 是否含税、运费、卸货、上楼、托盘/包装回收、破损补货 |
| 配套材料 | 砌筑砂浆/薄层砂浆、拉结件、门洞系统、抹灰材料是否另购、按多少袋/件计 |
| 售后与余料 | 错发、混批、破损如何退换；整托未拆和零散余料能否退、期限和运费 |

渠道可比较本地新型墙材/建材经销商、生产企业直供和可追溯的工程材料门店。直供不天然比经销商好；重点是生产企业和实际厂址可查、标签/批次可追溯、报价包含内容一致、能开具交易凭证并落实破损/补货责任。不要只看“江苏本地厂”或经销商门头地址。

## 砌块到货怎么验：从订单、标签到实物抽查

到货前把设计/确认单、报价、送货单和包装标签放在一起对照。不同生产批次、规格或等级分区码放、挂牌，不要先混堆再问。

| 检查项 | 现场怎么查 | 不一致时怎么做 |
| --- | --- | --- |
| 生产者与生产地址 | 看包装/随货合格资料上的生产企业全称和生产地址；分清销售公司、仓库/发货地与实际生产厂地址 | 要求供货方书面说明生产厂，标签和合格资料无法对应时先隔离该批，未核实不砌入墙体 |
| 产品标准和名称 | AAC核对是否标示`GB/T 11968-2020《蒸压加气混凝土砌块》`及产品全称；其他砌块/板材核对应产品标准和系统资料 | 标准号、产品名或交付实物不匹配，暂停接收/施工并由你和供货方核实，留存标签照片和送货单 |
| 强度、干密度/等级 | 抄录标签上的强度级别、干密度级别（如标准和产品要求标注），对照图纸、订单和产品报告；不能把“B06”当成强度等级，也不能用“高强度”宣传语代替数据 | 等级缺失或与设计/订单不符，先隔离并要求更正或换货；需要确认性能时看对应产品/批次检测资料，不靠手掰或敲声判定 |
| 尺寸和厚度 | 每种规格从不同托盘/堆垛随机取样；用卷尺测长、宽、厚并记录，查看尺寸差异是否影响排版、墙厚、门洞和灰缝 | 尺寸偏差造成墙厚/洞口无法满足图纸时暂停砌筑，要求供货方处理并重排数量，不能靠厚抹灰补救 |
| 批次、日期、数量 | 看批号、生产/出釜日期、托盘标记和送货数量；拍全标签；江苏住宅工程技术要求涉及块材龄期时，核对日期并按适用标准/设计确认 | 混批先分垛，不同批次不得不加区分地混砌；短少、无日期或无法追溯时，在送货单注明并联系供货方 |
| 外观与含水/破损 | 抽看整块和断面：崩角裂纹、明显翘曲、掉粉、泡水/雨淋、托盘受潮；仅比较同批材料，不用滴水测试替代指标检测 | 严重破损、受潮/冻损或批内差异明显的单独标记、拍照、清点，等供货方确认可用范围或换货，不拿碎块大量拼进门边和墙角 |
| 文件和交易凭证 | 保存送货单、合格证/检验资料、发票或交易记录、标签和托盘照片；记录墙体位置和批次对应关系 | 先补齐资料再使用；对强度、密度等有争议时封存同批样品并委托有资质机构检测，现场手段只能筛查明显异常 |

“优等品”不是对所有砌块都统一适用的营销等级；按该产品执行标准和合同约定核验其分类。也不要要求所有墙材都贴同一种CCC标志，先核该产品类别是否在强制认证目录及证书是否覆盖具体生产者、厂址和型号。材料产地本身不等于质量结论，具体看工厂、批次、检测资料和售后责任。

## 砂浆、拉结件、网布和门洞材料怎么配

| 材料/辅件 | 到货与相容性核对 | 现场用途和误区 |
| --- | --- | --- |
| 砌筑砂浆/薄层砌筑砂浆 | 核产品全称、用途（砌筑而非抹灰/瓷砖胶）、适用块材、强度等级、执行标准、净含量、生产日期、保质期、批次；预拌砂浆按包装加水和搅拌说明施工 | AAC薄层砌筑用对应专用砂浆时，灰缝厚度按该墙体系统和说明书控制；不混入水泥、胶水或现场随意加砂，不把抹灰砂浆拿来砌墙 |
| 拉结筋/连接卡件 | 型号、材质、防腐、长度、孔位/槽位及与砌块或板材系统匹配；植筋胶/连接件查看品牌、批次、有效期和安装说明 | 位置、数量、间距、锚固长度以设计/系统节点为准；不把短钢筋塞进灰缝就算拉结，也不未经结构确认在梁柱上钻孔植筋 |
| 过梁、边框/加强构件 | 现浇或预制型号、截面、钢筋/型钢配置、支承和连接方式以结构/墙体设计为准；预制件核生产标识、规格和无裂损 | 门洞上方不是放木板、几根钢筋或随手找根角钢就完成；不能自行套用“每边支承多少”或钢筋根数，缺节点先停下请设计补充 |
| 抗裂网/护角 | 网材类型、耐碱性能/防腐、幅宽、网孔、单位面积质量等按基层、砂浆和设计/产品系统核对；金属网不得锈蚀，玻纤网须适用于水泥基材料 | 用于设计/适用标准要求的不同材料交界、线槽修补或抹灰加强；搭接宽度以设计/系统规定为准，网要压在砂浆层内，不是干贴在墙面或外露 |
| 重物预埋/加固件 | 先拿到实际挂件类型、估计荷载、安装孔位与墙体系统，按厂家/设计选预埋木方、钢板、加强龙骨、混凝土块或专用锚固方案 | “要挂电视/吊柜”须记录加固范围、中心高度和可固定区；随手埋一截木头但没防潮/固定、或把普通膨胀螺栓当通用解法都不可靠 |
| 抹灰砂浆、界面材料 | 核对适用基层（AAC、混凝土、旧抹灰等）、室内/潮湿区域用途、配套底层/面层、厚度和养护要求；不得把界面剂当作修复空鼓的胶 | 仅对计划在本阶段完成的基层修补/抹灰使用；线槽大面积修补等候05、06工序，最终腻子找平在10阶段 |

### 砂浆一袋一袋怎么管

到货拍包装正反面，记下产品型号、批次、生产日期和保质期；袋子离地、防雨、按先进先出使用。搅拌时用量杯/秤按厂家水料比，先量水再加料，记录搅拌时间；说明书要求静置再搅拌的照做。结团、过期、受潮硬化、已经初凝的砂浆不加水“复活”。要求工人现场示范一盘，观察其是否把砂浆用在对应块材、是否超过可操作时间。

用量按墙体净面积/净体积、实际块材规格、洞口扣除、灰缝和系统损耗核算。不要用一个固定“每平方米几袋”套所有墙厚、规格和施工法；让供货方按具体型号技术表给理论耗量，再加上双方约定的施工损耗，写入采购清单。

## 施工怎么做：按隐蔽节点设停看点

### 1. 放墙线并复核完成尺寸

把墙中心线/边线、门洞边线和完成面线都标在地面、顶面及相邻墙面。用卷尺复核每面墙的起止点和对角关系；厨卫、柜体、门套一侧尤其要把瓷砖/抹灰厚度加回去。你、做墙工人和后续门/柜相关人员在图纸上确认起止尺寸，手机拍下带编号的全景。

### 2. 基层与墙脚处理

清除浮灰、油污、松散砂浆和积水，检查楼板、梁柱侧面是否坚实；发现裂缝、渗漏、结构缺损或旧抹灰大面积空鼓，先停该处并确定修复方案。新墙是否做混凝土坎台、防潮层或其他墙脚节点按设计、湿区防水节点和墙体系统，不把“所有卫生间统一砌现浇反坎”写成未经核实的通用要求。

### 3. 先做一段样板，核对材料与灰缝

在不影响结构的墙段先砌一小段，检查块材与砂浆是否匹配、灰缝是否均匀、墙面是否能按控制线收齐。确认后再继续。同一面墙不随意换块材或砂浆；不同规格/批次须分区并更新排版。

### 4. 砌筑时盯错缝、饱满和门边完整块

- 按墙体排版错缝砌筑，控制皮数、灰缝和墙体垂直/平整；AAC砌块搭砌长度、灰缝饱满度按GB 50203适用条文、设计及所用薄层系统要求检查。
- 让工人在首段完成时揭开一处新砌块查看砂浆铺展/粘结，不能只在四角点粘或用碎块塞满主要墙身；具体检查按砌体类型和所用砂浆方法执行。
- 门洞边、墙端和设备洞口尽量使用完整块/系统配套切块，切块后不得薄片拼凑；需要嵌件的在砌筑时放入并拍照。
- 每砌完一段就用靠尺、线坠/水平尺复核，偏差在砂浆允许调整期内修正；不能等抹灰时靠厚薄不均“找直”。

### 5. 新墙与旧墙/主体怎么连接

先按图纸/节点确认是拉结筋、连接片、柔性连接还是条板系统专用卡件；看连接位置、数量和固定是否完整，拍摄带尺照片。植筋孔径、孔深、清孔、胶量和固化时间不能由业主凭经验指定，须按设计、胶产品说明和施工规范由实际操作人完成；若需在主体结构钻孔且无明确节点，先停并取得专业确认。

### 6. 门洞过梁、门垛与门框固定

砌到门洞前，把门厂/门店给出的洞口要求和设计节点放在现场核对。过梁型式、截面、配筋、支承和是否需要洞边加强依设计和墙材系统决定；不得以薄木板、松动角钢、碎砖加砂浆代替。需要后置门框固定件时，按门厂和墙体材料系统确定位置/数量，不能让射钉直接打进砌体；GB 50210-2018第6.1.11条明确砌体上的建筑外门窗严禁射钉固定，室内门套固定则按其产品和基层方案执行。

洞口复核至少量上、中、下三处净宽，左右两侧分别量高度，再量两条对角线；记录墙厚、垂直和平整。尺寸以门/门套供应商书面要求的“毛洞口”口径为准，分清是否包含地面完成高度、门槛、瓷砖和门套收口。不能把标准允许偏差当成定制门洞的目标尺寸。

### 7. 顶部收口：填充墙不等于板墙

砌体填充墙与承重主体结构之间的空隙处理，`GB 55007-2021`要求在填充墙砌筑14天后进行。这个14天是该连接空隙处理的时间要求，不是所有新墙一律等待14天后才能做任何事；具体留缝和填塞构造按设计。条板墙、龙骨板墙采用其系统规定的顶部卡件/柔性缝等做法，不照搬“斜砖顶紧”。墙顶不得用碎砖、发泡胶或松散砂浆随手塞满来掩盖未确认的连接。

### 8. 挂重物的加固必须在封闭前留证

按家具/设备图标出吊柜、电视、热水器、浴室柜、扶手等固定区；让工人说清用什么加固、范围多大、厚度/高度如何定位，以及后续螺钉可落在哪一区域。封闭或抹灰前用卷尺拍“房间全景＋加固近景＋两方向尺寸”，写进竣工图/照片说明。后续安装时不得超出加固区；若位置改变，先由对应安装工和墙体工人复核固定方案，不盲打膨胀螺栓。

### 9. 抗裂网与基层修补怎么做

混凝土与砌体、不同砌块、墙体与线槽等交界处，是否需要加强以及采用耐碱玻纤网还是金属网，应按适用标准、设计和砂浆系统确定。网片要按规定位置和搭接压入砂浆，不能贴在干墙面上再薄薄盖浆，也不能用网片遮住未填实的深槽、活动裂缝或空鼓基层。

基层修补先敲除已经松动/空鼓的表层到坚实边缘，清理灰尘，必要时按材料说明润湿或涂刷界面材料，再用与基层适配的砂浆分层修补；单次厚度和层间等待按产品说明。修补前后同角度拍照。水电管槽尚未施工的先只做允许的墙体基础处理，不预先把未来槽口批死。

## 常见问题：别把抹灰当成万能遮羞布

| 看到的现象 | 常见原因/风险 | 你怎么核查 | 怎么处理、何时复工 |
| --- | --- | --- | --- |
| 墙线正确但砌完后通道/柜位变窄 | 只按砌块面放线，未加两面抹灰/砖/柜体净尺寸 | 对照完成面线和设备图复尺，核实总墙厚 | 未继续砌筑前调整；已砌部分先复核拆改和结构边界，再书面确认变更 |
| 新旧墙交界后期开裂 | 拉结/柔性连接缺失、基层不同、抹灰加强不当或基层未稳定 | 查覆盖前照片、连接件位置、裂缝是否贯通/发展 | 不能只贴网盖裂缝；先判明活动性和原因，方案确定后修复并观察复验 |
| 墙体上宽下窄、表面波浪 | 砌筑时未逐段吊垂直/靠尺控制，后续试图厚抹灰纠偏 | 2m靠尺、线坠或激光分段检查，标出超差区 | 超过约定/适用标准时先修墙体，不用不均匀厚抹灰补救 |
| 门洞上沿下沉、洞口裂纹或过梁松动 | 过梁/支承/洞边构造不适合跨度荷载，或施工顺序不当 | 停止装门；拍照并对照设计节点，观察裂缝、变形 | 不用木条顶住后继续；由设计/结构专业人员确认修复方案后再施工 |
| 门洞尺寸合格但门装不上/缝隙不均 | 量的是毛洞口却按完成面尺寸下单；两侧垂直、对角线未检查 | 找门厂核对量尺表、安装方式和墙厚，重新量上中下、左右、对角 | 先由门厂复尺；未确认前不砌小门垛、不剔结构边、不下单生产 |
| 挂柜/热水器位置没有可用基层 | 加固位置没在砌筑/封板前确认，或只用普通膨胀件 | 对照设备安装图找加固照片、尺寸和材质 | 未覆盖时补做经确认的加固；覆盖后不盲打孔，交设备厂家/专业安装工确定锚固 |
| 墙脚潮湿或卫生间墙体开裂 | 墙脚/防水接口没有按设计做；墙材受潮或防水做法错误 | 查供货日期、潮湿来源、墙脚节点和后续防水图 | 先排除漏水/基层问题；不得用防水涂料或腻子遮住持续潮湿 |
| 抹灰空鼓、裂纹、掉粉 | 基层有浮灰/油污、吸水处理不合适、层过厚、砂浆不适配或养护不足 | 轻敲作筛查并标范围；看边缘是否松动、裂纹是否扩大 | 空鼓范围铲到坚实基层，纠正基层/材料/厚度后修补；达到规定条件再复验 |

## 偷工减料或需要停下来的信号

- “反正后面抹灰能盖”——先拿靠尺和卷尺复核；位置、厚度、洞口超差先修正，不能把误差交给抹灰层。
- 门洞没有过梁/节点，工人准备塞木板、角钢或碎砖——暂停砌筑该洞口，取得设计/系统做法。
- 拉结筋、网片或重物加固已经被盖住却没有照片/尺寸——暂停下一面墙或抹灰，要求补充可验证记录；无法验证时请专业人员评估是否需要开验。
- 砌块标签被撕、生产厂/批次不明，或不同规格混在一起——先分垛核实，不把来源不明材料砌进墙内。
- 砂浆过期、结块、随意加水/水泥，或把瓷砖胶、腻子当砌筑砂浆——停用该批，按包装和产品体系重新配料。
- 对结构开槽、梁柱植筋、扩大洞口或墙体落地承载有疑问时，工人说“大家都这么做”——停对应位置，拿到设计/结构专业意见再继续。
- 为赶工把不同墙体系统的卡件、砂浆、网布混用，或未按说明等待就顶紧、抹灰——对照系统说明整改，并按要求等候/复验。

## 开工前和工人逐项确认

1. 这面墙的墙体系统、厚度、强度/密度要求和两面完成面尺寸分别是多少？图纸版本是哪一版？
2. 门洞按哪家门厂的毛洞口尺寸预留？过梁型号/节点、两端支承和门框固定位置依据哪份图纸或产品说明？
3. 墙体和原墙/梁柱侧、顶部的连接形式是什么？哪些位置需要先拍隐蔽照片？
4. 哪些位置要挂柜、电视、热水器、扶手或其他重物？加固范围和可打孔区如何标尺寸留档？
5. 用哪种砌筑砂浆/薄层砂浆，适用这批砌块吗？一袋加水量、搅拌/静置、可使用时间按哪里说明？
6. 湿区墙脚、防水、穿管和瓷砖墙面怎么衔接？哪些工序留到07防水和08贴砖？
7. 墙顶空隙何时处理？是否属于需要等待的砌体填充墙连接节点？适用哪条设计/系统要求？
8. 价格按块、立方还是墙面积算？拆包、切块、门洞、过梁、加固件、运料上楼、垃圾和基层修补是否另计？变更先报量报价再做。
9. 工人由谁带班/与你对接？只请一人时由谁直接联系？疑似结构、燃气、电气或管线问题由谁停工、由你联系哪位专业人员？

把答案写在报价清单、墙体图或双方可回看的聊天记录里。你自己找工人，不需要另设装修公司项目经理；多人施工时可约一名带班工人负责沟通，但他不替代设计/结构或专业机电人员。

## 过程检查：三个时间点到场最有用

1. **第一段墙砌完**：核对标签、墙厚、灰缝、错缝、垂直平整和连接做法，确认样板后再扩大。
2. **门洞/拉结/加固还没被遮住**：量洞口和加固区，查看过梁、连接件、预埋件是否与确认节点一致；拍带尺照片。
3. **完成后、水电开槽前**：复核墙位、厚度、洞口、表面和顶部收口；把禁止开槽/禁止打孔区域标记在图纸上交给05阶段工人。

检查时让工人暂停、清掉遮挡后再量。不要站在切割/搬板/高处作业区域围观，也不要自己操作植筋、电锤或切割设备。

## 等待与停检：哪些要等，哪些不能统一写“几天”

- **填充墙顶部连接**：砌体填充墙与承重主体结构之间空隙处理按GB 55007-2021等待砌筑完成14天后进行，并按设计节点施工；这不是所有墙板系统都通用的14天停工规则。
- **抹灰/基层修补**：基层状态、砂浆品种、厚度、室内温湿度影响养护与干燥。以产品说明、设计/合同及适用标准的要求为准；江苏工程质量通病标准里针对住宅工程的建议等待期不能直接变成每套家庭装修统一天数。
- **后续开槽**：墙体和砂浆达到对应系统允许开槽条件后，才让05水电工按图开槽；禁止在新砌墙尚松动、连接尚未处理时先开槽。

**必须停检的隐蔽项**：拉结/连接件、过梁和洞边加强、挂重物加固、板墙内部连接/填充、墙脚防潮/防水接口以及计划被抹灰覆盖的抗裂网。检查完成并拍照后才覆盖。墙面槽口修补则留在05完成后处理。

## 验收怎么做：工具、数值和适用范围

准备当前版墙体图、卷尺、2m靠尺、塞尺、2m垂直检测尺/线坠、水平尺或激光水平仪、记号贴和手机。按“图纸定位 → 墙体尺寸 → 垂直平整 → 洞口 → 隐蔽记录 → 表面缺陷”逐项检查，问题编号后整改复测。

### 砌体填充墙尺寸允许偏差

如果本阶段使用的是适用`GB 50203-2011《砌体结构工程施工质量验收规范》`的砌体填充墙，可参考表9.3.1：

| 检查项目 | 表9.3.1允许偏差 | 现场检查 |
| --- | ---: | --- |
| 轴线位置 | 10mm | 对确认的定位线用卷尺量至墙面/墙轴线，记清基准 |
| 墙体垂直度（墙高≤3m） | 5mm | 2m垂直检测尺或吊线检查 |
| 墙体垂直度（墙高>3m） | 10mm | 吊线/测量工具检查全高，并记录检查长度 |
| 表面平整度 | 8mm | 2m靠尺贴墙，最大缝隙用塞尺测量 |
| 后塞口门窗洞口高、宽 | ±10mm | 按同一毛洞口口径量上中下、左右；定制门应同时满足门厂更严的书面要求 |

这些值针对标准适用的砌体填充墙尺寸/位置验收，不可直接拿来验收AAC条板、轻钢龙骨墙或最终抹灰层。抽检验收要求也不意味着业主只需量一个点；家庭实用检查应对每面关键墙和每个门洞多点量，并优先满足设计、合同和门厂接口。

### 抹灰基层平整度

若本阶段确实包含一般抹灰，`GB 50210-2018`表4.2.10的普通抹灰立面垂直度、表面平整度允许偏差为4mm，高级抹灰为3mm；普通抹灰阴角方正按表注可不检查。用2m垂直检测尺/靠尺和塞尺检查。应在报价/合同里写清采用普通还是高级抹灰，并确认后续腻子、瓷砖对基层另有更严要求时如何处理；不能把4mm抹灰验收值当成最终涂料或大砖铺贴的平整度目标。

同时目测并轻敲筛查贯穿裂缝、松动、脱层、明显空鼓、掉粉和门洞角部斜裂纹。轻敲只用于定位表层异常，不能据此判断墙体结构安全。裂缝若贯穿、持续发展或伴随变形，停止覆盖并请专业人员判断。

### 门洞、墙厚和接口复核

- 洞口：上/中/下宽度、左/右高度、两条对角线；记录毛洞口尺寸和完成面/门套需求，交门厂复尺确认。
- 墙厚：洞口侧边测结构/砌块厚度；完工面再测总厚，扣除两边抹灰/瓷砖等层次后与墙体方案核对。
- 墙位：从固定基准点量墙端、门边和设备中心线；重点复核走道净宽、柜体净深、洁具空间和开门回转。
- 连接与加固：对照覆盖前照片和节点，核实每面墙编号、加固区域、门洞过梁及墙顶做法；缺记录或被覆盖无法确认时先不放行。
- 给后续工人交接：把实际墙位、洞口、墙厚、加固区和不可随意开槽区写到最新版图纸，并让05水电、门/柜安装相关人员确认收到。

## 整改、复验与放行04/05阶段

1. 对超差墙位/洞口、裂缝、空鼓、松动和隐蔽节点问题贴编号；拍全景、近景、带尺照片，记责任人、修复方式和复验日期。
2. 先确认原因和修复做法，再动手。涉及主体结构、门洞过梁、连接件、燃气/电气管线时，请相应专业人员确认，不让普通工人用砂浆遮盖。
3. 整改后用原测量点、原工具、同角度复拍；如果墙位或洞口改变，更新图纸并通知门、柜和设备供应方重新复尺。
4. 保存产品包装/批次、送货单、砂浆说明、隐蔽照片、墙体实测记录、书面变更及整改复验记录。

**放行条件**：新墙和门洞达到设计/合同及所用墙体系统要求；连接、过梁、加固等覆盖前已检查留证；异常裂缝/松动问题已闭环；实际墙位和门洞尺寸已更新；禁止开槽/打孔区已交给后续工人。通过后再放行04门窗/设备前置或05水电，并按双方事先约定的验收节点支付相应工钱。
