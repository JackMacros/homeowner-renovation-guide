# 02 拆除与清运

[上一阶段：现场保护与施工放线](01-site-protection-and-layout.md) · [返回整体流程](../00-process-overview.md) · [下一阶段：砌墙、门洞与基层修补](03-masonry-and-repair.md)

[打开本阶段一页式现场清单](../checklists/02-demolition.md)

## 阶段目标

只拆除经核实允许拆除、且已在图纸和现场明确标出的饰面、非承重隔墙或局部构造；保护主体结构、保留墙体、管线和相邻住宅；按物业及属地规则完成垃圾收集、运输和交接。拆后现场应能检查原基层、准确复尺，并具备进入03阶段砌墙、门洞与修补的条件。

**本阶段原则：**“敲起来像空心”“邻居家这样拆过”都不能证明墙能拆。你负责确认边界、手续、费用和验收放行；自行聘请的工人只能按确认范围施工，不能替代结构设计、鉴定或法定审批。涉及主体/承重结构、梁柱楼板、剪力墙、阳台连接墙、结构洞口扩大或发现钢筋混凝土构件时，禁止按普通拆墙继续作业。

### 谁来和工人对接

你不需要额外聘一个装修公司项目经理。如果同一阶段有几位工人一起干，开工前约定一位带班工人作为日常联系人，负责复述当天范围、协调工序、发现异常时先停下并通知你；若只请一位工人，就由你直接和这位工人确认。这个联系人只是沟通与现场协调角色，不是结构鉴定人，也不能替代需要资质/资格的专业人员或法定审批。

## 进场条件

- 01阶段已签认的拆改图、现场放线照片和图例在场；当前版本/日期明确，口头变更已回写图纸并确认费用、工期影响；
- 拟拆构件的性质、范围、墙厚、相邻构造和保留侧已经核实。只有“敲击声音”“开发商户型图线型”或工人口头判断，不作为允许拆除的依据；
- 江苏省物业装修告知/登记及服务协议已办理；施工时间、电梯保护、垃圾暂存点、清运路线和指定处置方式已按所在城市/小区要求确认；
- 可能受影响的电线、给排水、燃气、供暖、空调冷媒、弱电等，已由你与工人确认由谁联系相应专业人员辨识、断开或保护；你和普通拆除工人都不自行拆改配电箱、燃气管和公共管线；
- 电梯、门窗、保留面及管口保护仍有效；搬运路线畅通，楼板上没有将要拆出的建筑垃圾集中堆放；
- 拆除工具、粉尘/噪声控制、个人防护、消防措施和紧急联系人已由你与带班工人（如有）逐项确认，并告知每位进场工人；有住户、物业或邻居需要告知的，已按小区流程安排。

有任何一项未完成，先补资料或核实，不以“工人已经到了”作为开工理由。

## 工作内容

- 对确认可拆的饰面、非承重隔墙及局部构造进行受控拆除；
- 保护与拆除区域相邻的墙、门窗、设备和管线；发现隐蔽构件/管线异常立即停在安全状态并报告；
- 按物业、所在城市及合同约定分类、装袋、暂存、下楼、外运和交接建筑垃圾；
- 清理松动但不擅自扩大拆除/凿除范围；
- 拆后检查结构、保留面和原基层，复测门洞、墙位和通道，形成03阶段可用的现场尺寸与问题清单。

## 拆除范围怎样确认：先分清“饰面、隔墙、结构”

| 对象 | 业主现场识别和处理原则 | 是否可以按普通拆除继续 |
| --- | --- | --- |
| 墙面砖、地砖、抹灰层、吊柜/非结构装饰 | 对照设计/拆改图及保留要求，确认基层后面没有水电、防水或需保留饰面；先做小范围确认拆除边界 | 仅限图纸确认的饰面范围；发现管线、防水层或基层异常立即停该处 |
| 轻质非承重隔墙 | 依据原始建筑/结构资料、物业资料和必要的专业意见核实，记录墙厚、与梁板柱/相邻墙的连接关系；不能只凭敲击声音判断 | 经核实允许拆除、放线签认后，工人按确认范围和专业意见确定的安全方法作业 |
| 梁、柱、剪力墙、楼板、承重墙、结构连梁/过梁、钢筋混凝土构件 | 按结构图和专业意见确认；发现钢筋、混凝土构件、结构连接部位或异常裂缝时，保护现场并请设计/结构专业人员核实 | 不得作为普通拆除项目施工。涉及建筑主体/承重结构的，按法规取得设计方案和批准手续；物业登记不能替代审批 |
| 阳台与室内连接墙、外墙、烟道、公共立管、燃气/供暖设施 | 依法规、设计和物业资料分别核实用途、产权/管理边界、审批要求和专业施工单位 | 不得擅自拆、改、移或封堵；未取得适用手续及专业方案不得动工 |

图纸、物业资料和现场情况相互矛盾时，先停止相关部位拆除。不要用“先砸开看看”来代替结构核实；确需探查时，由负责方案的专业人员确定安全的探查方式和范围。

## 拆除前：施工范围、隔离和费用逐项锁定

### 给工人的拆除交底单

每一个拆除区域应有唯一编号（例如“厨房北墙 D-01”），现场和图纸能一一对应。交底单至少记录：

| 字段 | 写什么 |
| --- | --- |
| 位置和边界 | 房间/墙面方向、起止点、拆到哪里、保留哪一侧；用现场照片标出边界 |
| 构件判断 | 饰面/隔墙/结构或待核实；判断依据来自何种图纸、专业意见或批准资料 |
| 目标尺寸 | 拆后墙位、洞口宽高、保留墙垛、门套/饰面完成面等；标明尺寸的起止面 |
| 相邻保护 | 门窗、墙角、楼板、管线、地漏、公共区域和邻接房间如何防护 |
| 施工限制 | 禁用/限制的设备或区域，施工时段、降尘、噪声、垃圾暂存及搬运路线 |
| 异常停工联系人 | 业主、带班工人（如有）、物业及结构/机电专业人员的联系方式；任何工人发现异常都先停相应作业并联系业主 |
| 报价和责任 | 拆除人工、装袋、户内搬运、下楼、车辆、处置/物业费用、保护修复和超范围变更分别如何计价 |

### 临时设施和保护复核

1. 拆前拍原状全景、局部和管线/设备近照；照片带房间定位、日期。记录已有裂缝、空鼓、渗水、崩角、门窗损伤，与工人及物业共同确认原有状态。
2. 再走一次拆除及清运路线，核保护板未移位，电梯/楼道要求已交接，门窗可关闭，地漏/排污口堵头可见可拆。检查相邻房间及必要的公共部位，作为后续损伤对比。
3. 由你和带班工人（如有）落实相应专业人员核实并隔离可能受影响的电、水、燃气、供暖和弱电；不能确认管线归属/状态时先停，不让业主或普通拆除工人带电试拆、切割管线。
4. 垃圾暂存点、装袋规格、每日清运安排和允许使用的电梯/时段明确。不得把垃圾长期堆在楼板局部、楼梯间、消防通道或未获许可的公共区域。
5. 防尘隔离不能遮挡逃生/消防设施；拆除工人自备/使用的粉尘控制工具和个人防护用品，应由带班工人（如有）与每位作业工人开工前核对。涉及疑似石棉、化学污染、腐朽或其他异常材料时，不自行打碎/扫除，暂停并请专业人员识别处理。

## 拆除方式：按构件和保留边界选择，不按速度选

| 方式/场景 | 适用前提 | 主要利弊 | 业主现场关注 |
| --- | --- | --- | --- |
| 人工小工具分段拆除 | 已确认可拆的局部饰面、轻质构造或靠近保留边界的位置；由实际施工工人按确认范围和专业要求作业 | 速度相对慢、边界较易控制；人工时间长，仍会产生粉尘、噪声和冲击 | 第一处先按已签边界试做，确认保留侧未松动、管线无异常再扩展 |
| 电动/机械工具局部拆除 | 工人确认基层、构件和邻接部位适合使用该机具，并能控制飞溅、振动和粉尘；结构疑点交由专业人员核查 | 效率较高；振动、误切管线/钢筋、崩坏保留面风险上升 | 工具更大不等于更合适；靠梁柱、楼板、管线和保留墙边时，先确认作业范围、保护措施及停工信号 |
| 饰面层选择性拆除 | 只需去除砖、抹灰或局部基层，且确认不破坏后续要保留的主体/防水/管线 | 可减少垃圾和对基层的破坏；饰面与基层粘结牢固时边缘可能扩裂 | 先确认拆除深度；每扩一层都复查基层和隐蔽设施，不以“全部铲到红砖”作为默认要求 |

施工工具的型号、操作顺序、支撑/临时加固等应由实际作业人员按适用方案确定；涉及结构判断或临时加固时由相应专业人员提出意见。业主不应要求工人对结构构件试砸、切筋、开槽或扩大洞口来“现场验证”。

## 拆除施工顺序：每一段都要有停看点

1. **确认当天作业面**：带班工人（如有）或实际作业工人拿确认版图纸，和你复述“今天拆什么、不拆什么”；作业区设置警示和隔离，非施工人员退出。
2. **复查管线和保护**：工人核对已完成的管线隔离状态，查看保护、堵头和垃圾路线；失效项修好后才开始。
3. **先小范围确认构造**：在已经批准可拆的范围内，由工人用与部位相适配的方法暴露第一段基层；观察构造、厚度、连接方式及有无管线/钢筋/异常材料。此步骤不能用于探试承重墙或结构构件。
4. **按交底分段受控拆除**：工人按既定顺序拆除，不向保留侧无控制地扩展；垃圾及时装袋/清出，保持作业面可见，禁止以垃圾覆盖异常点。
5. **关键位置暂停检查**：拆到新旧墙交界、门洞边、管井/烟道邻近、梁柱边和管线交叉处时，停下来让带班工人（如有）与你复核；边界或构造与图纸不符则暂停该处并记录。
6. **完工清理但不扩大凿除**：移走碎块、松散且确认允许清理的残留物，显露基层；对超出交底范围的硬化层、钢筋、混凝土或防水层不得擅自继续凿。
7. **复尺、拍照并签认**：对照原图记录实际拆后尺寸和保留构造；完成拆前/过程/拆后三组照片及垃圾交接记录，由你确认后才进入03阶段。

你不必长时间停留在粉尘区。建议在第一处拆除前、第一处构造暴露后、当天清运结束后到场检查；每次先让工人停机、清理视线再看，不能在飞屑和高噪声作业中靠近围观。

## 建筑垃圾怎么收、怎么运、怎么核账

拆除垃圾的类别、投放点、预约方式、清运单位/车辆和费用可能按江苏各市及小区管理规则不同。开工前向物业或属地主管部门核实本项目适用做法；不能把南京、苏州某小区的流程当作全省统一规则，也不能把装修垃圾直接当普通生活垃圾投放。

### 把报价拆到能对账

把你和工人谈妥的报价写成清单或聊天记录，至少分列：

- 拆除人工：按墙体/饰面范围、工时或项目清单计价，注明含不含基层清理；
- 装袋/分类：袋子或周转箱由谁提供、垃圾如何分类、破袋和超重由谁处理；
- 户内搬运和下楼：搬运距离、楼层、电梯或楼梯限制、人工/设备是否另计；
- 公共区域保护和清洁：电梯/楼道二次保护、每次运输后的清扫责任；
- 外运车辆与处置：车辆类型、预约/进场费用、属地指定收运或处理费用，是否有称重/交接凭据；
- 超范围变更：发现隐藏构造、增加拆除量、额外修复时，先拍照、报量、报价、书面确认，再实施。

报价只有“拆除清运一口价”时，让对方明确包含范围、垃圾量假设、楼层/距离、物业收费、清运次数和超量算法。比较不同队伍报价时使用同一拆除图、同一垃圾路线和同一计价口径。

### 装袋和运输现场怎么查

1. 可回收物、装修垃圾和需要单独识别的异常材料按属地和物业要求分类；装袋/容器不要超出工人安全搬运能力，也不要让尖锐碎片刺穿袋体。
2. 作业面垃圾及时装袋移出，但不在楼板、阳台、楼梯平台或公共通道集中堆放；物业规定临时堆放区域时按指定范围、时间和覆盖方式执行。
3. 运输前确认袋口扎紧、路线铺设保护、电梯/楼道没有障碍；运后及时清理洒落碎渣和粉尘。不得把水泥浆、灰浆和碎屑冲进地漏、雨水口或污水管。
4. 需要预约物业/属地清运或有偿处置的，保存预约记录、收据/发票、称重单或物业交接记录（当地提供哪种留哪种）；若你委托工人代办清运，事先写清谁负责合法交接及异常退运费用。
5. 清运结束走查室内、楼道、电梯和垃圾暂存点；在合同/交接单上记录已清运批次、遗留量和待处理项，不能只凭“车走了”认定完成。

## 拆除材料和工具：业主核对“适配与防护”，不代替工人操作

本阶段一般无需你自购拆除机具。工人通常自带作业工具和个人防护用品；你重点核对保护、管口封堵和垃圾用品是否满足现场需要，并在开工前约定由谁提供、损耗后谁补充。

| 用品/设施 | 到场核对 | 使用边界 |
| --- | --- | --- |
| 防尘隔离膜/封闭材料 | 核覆盖范围、固定方式和是否影响通风、消防、门窗/设备操作；公共区域按物业要求 | 不堵安全出口、消防设施、排水孔和检修口；每日查看破损并及时恢复 |
| 地面/门窗/电梯保护板与护角 | 核与01阶段确认的保护范围相符；检查破损、受潮、尖角和固定是否松动 | 先清理基层再铺，不能让碎粒夹在板下；搬运路线要覆盖连续，不能只铺一小块拍照交差 |
| 管口堵头与警示标签 | 逐一核管径/接口、数量、固定和可拆性；颜色/标识便于拆后核销 | 不用抹布、泡沫碎料或砂浆塞口；堵头不得掉进管内或被拆除物掩埋 |
| 垃圾袋/周转容器 | 核规格、数量和是否适用于碎砖、砂浆等尖锐/重物；备有破袋替换措施 | 不过量装填、不拖拽划伤公共地面；垃圾分类和投放依属地规定 |
| 拆除工具、降尘设备、个人防护 | 由实际作业工人说明工具适用于当前部位；你检查防护用品完好且每位工人都有 | 你不拆机、不操作、不判断工具内部电气安全；出现飞溅/异常振动/管线风险时要求停工核查 |

## 常见问题：看见什么、如何处理

| 现场表现 | 可能原因/风险 | 业主核查 | 处理与复工条件 |
| --- | --- | --- | --- |
| 工人仅凭敲击声说某墙可拆 | 把声音当成结构鉴定，可能拆错承重/剪力构件 | 对照结构/建筑资料和专业意见，确认墙体类别、连接位置及审批文件 | 资料未能确认时停止该墙拆除，补齐专业核实和适用手续 |
| 拆开后见钢筋、混凝土、梁/柱/连梁或厚实构件 | 图纸与现场不符，可能伤及主体结构 | 立即停该处；不切割、不弯折、不用砂浆掩盖，拍全景/近景并通知专业人员 | 有具备相应能力的专业人员书面判断和方案；依法需审批的先取得手续 |
| 发现水管、电线、燃气/供暖/冷媒管或不明套管 | 可能造成触电、漏水、燃气泄漏、系统故障或影响邻户 | 停止相邻工具作业，人员退至安全位置；由你联系对应专业人员辨识/隔离 | 管线性质和状态确认、损伤检查及修复测试完成后，你与相关专业人员确认复工条件 |
| 保留侧墙皮大面积脱落、新裂缝或门窗变形 | 冲击过强、支撑/连接受损或原有缺陷暴露 | 与拆前照片比对，标记裂缝端点、拍同角度全景/近照；必要时通知邻居/物业检查相邻部位 | 先专业判断是否结构/安全问题；责任和修复方案明确、复验通过后再继续 |
| 建筑垃圾掉进地漏/立管，或管口堵头消失 | 封堵未固定或垃圾管理失控，后续可能堵塞 | 先核销封堵点位表，不往管内加水冲洗或硬捅 | 请专业人员清理并确认排水通畅；该点恢复封堵后才继续湿作业 |
| 垃圾袋破裂、楼道/电梯有散落碎渣 | 超量装袋、无覆盖运输或清运线路不合理 | 走查搬运路线和暂存点，拍照记位置/时间 | 立即清扫，补袋并按物业要求恢复公共区域；重复发生时调整装袋/路线和责任人 |
| 工人建议先拆超出放线的部分，事后再补图/报价 | 现场变更失控，费用和结构责任不清 | 对照签认图纸标出超范围位置和尺寸 | 暂停新增范围，先完成书面变更、专业核实、费用确认再作业 |
| 拆完后仍有松动块、尖锐残留或无法复尺 | 清理/收边不足或施工垃圾遮住边界 | 清除表面垃圾后检查边缘，卷尺复测并对照放线图 | 与工人确认清理到03阶段能安全接续的状态；不允许后续用抹灰直接盖住未确认损伤 |

## 偷工减料或违规信号

- 说“敲起来是空的”就断定可拆，拒绝出示图纸依据或解释结构判断；暂停该部位。
- 在墙上画叉就开始砸，没有确认边界、保留侧、管线隔离和物业要求；先完成拆除交底。
- 发现钢筋、混凝土、未知管线或异常裂缝后仍继续切割/锤击；立即停工、保护现场并要求专业核查。
- 垃圾装得过满、在楼板局部堆放、塞进电梯/消防通道，或把灰渣扫进地漏；要求减量搬运、恢复封堵和清理。
- 用“后面抹灰能盖住”掩盖保留墙、门窗、立管或公共区域损伤；要求记录现状、责任、方案与复验结果。
- 报价未说明装袋、搬运、下楼、车辆、处置/物业费用，拆到一半才加价；暂停变更量，按合同书面核价后再做。
- 垃圾已运走却不给任何约定的交接/费用凭据，或让业主在未清空前签“全部完成”；按实际剩余量记录，不签与现场不符的结论。

## 开工前需要向工人确认

1. 哪些是今天允许拆除的墙/饰面？每段编号、起止点和保留边界分别是什么？
2. 墙体性质依据哪份图纸/专业意见确认？若暴露出钢筋、混凝土、管线或异常构造，谁下令停工、由谁核实、谁书面放行？
3. 水电/燃气/供暖等由谁辨识、隔离和恢复？本户与公共/邻户设施的分界如何确认？
4. 施工顺序、机具、粉尘/噪声控制、门窗/墙体保护及每日清理安排是什么？
5. 报价是否分别含拆除、装袋、户内搬运、下楼、外运、物业/处置费用和清运凭据？如何处理超出拆除图的变更？
6. 物业规定的时间、通道、暂存点、车辆和垃圾交接要求是什么？由谁预约、谁承担额外费用？
7. 拆前/拆后分别拍哪些照片、复测哪些尺寸？发现损伤由谁登记、判断责任、修复并复验？

确认结果写入报价/合同附件或施工群可追溯的书面记录；涉及结构、管线、公共部位和新增费用的变更，不能只留口头答复。

## 过程检查：三个必到场节点

1. **第一处开拆前**：核对当天位置编号和确认版图纸，检查保护、管口封堵、物业时间/路线、工具与隔离状态；不要在机器启动后才发现边界错误。
2. **第一处构造暴露后**：让工人停机清出视线，你与工人一起核对真实墙体/基层是否与图纸一致；发现钢筋、管线、渗漏或结构异常就停工并联系专业人员，不由带班工人自行作结构判断。
3. **清运完成、进入下一工序前**：室内及搬运路线清空，检查结构/保留边界、垃圾交接、基层、实际尺寸和问题整改；由你拍照、记录并签认放行。

出现以下情况不等到检查节点：疑似结构构件或钢筋、管线/燃气异常、漏水、突然裂响或振动、相邻部位出现新裂缝/变形、粉尘隔离/防护失效、垃圾堵塞消防通道。停相应区域作业，保护现场并通知负责人和专业人员。

## 等待与停检

拆除后通常没有固定的“养护几天”要求。必须等待的是异常调查、管线修复和测试、结构/基层修复方案、物业/属地清运交接及粉尘清理完成；具体时间以专业处理方案、产品说明和物业安排为准。任何未经复核的钢筋/结构损伤、渗漏、邻里裂缝、管线异常或超范围拆除，都不得被03阶段砌墙/修补覆盖。

**停检点**：拆除图与现场放线签认后才开拆；第一处构造暴露且与图纸一致后才扩大作业面；全部垃圾清走、拆后复尺、保留部位检查和问题整改完成后才放行03阶段。

## 本阶段依据与地域差异

- 江苏住宅装修应按《江苏省物业管理条例》第七十一条，在开工前向物业告知并办理登记、签订服务协议；对主体/承重结构的变动还需设计方案和依法办理批准手续。物业登记不是结构拆改许可。([江苏省人大：《江苏省物业管理条例》第七十一条](https://www.jsrd.gov.cn/qwfb/sjfg/202110/t20211008_1221223.shtml))
- 住建部《住宅室内装饰装修管理办法》对改变主体/承重结构、扩大承重墙原有门窗尺寸、拆除连接阳台墙体、超设计标准增加楼面荷载等行为设有禁止或前置要求；具体按现行规章条文、房屋所在地管理要求和专业设计/审批文件执行。([住房城乡建设部规章原文](https://www.mohurd.gov.cn/file/2022/20220228/8e2304b2-9f66-426b-ab25-6eda86fa0f67.pdf?n=%E4%BD%8F%E5%AE%85%E5%AE%A4%E5%86%85%E8%A3%85%E9%A5%B0%E8%A3%85%E4%BF%AE%E7%AE%A1%E7%90%86%E5%8A%9E%E6%B3%95))
- 建筑垃圾应按所在地分类投放、收运和处置要求办理。江苏省《建筑垃圾电子转移联单管理办法》自2026年5月15日起施行；住宅装修垃圾转移的联单经办主体可能是业主、施工单位或物业服务人，应事先问清本小区/属地由谁填报并索取可提供的交接凭据。([江苏省政府公报：苏建规字〔2026〕16号](https://www.js.gov.cn/art/2026/5/25/art_64797_11775947.html))
- 建筑垃圾投放点、预约/指定清运单位、车辆、时段、收费和凭据以房屋所在地城市及小区规则为准；江苏没有可据此概括所有城市的单一户内装修垃圾流程。开工前向物业/属地主管部门确认后，把要求写入合同。
- 本页关于保护、分段检查、粉尘/噪声控制和记录方式是业主管理建议，不代替拆除设计、结构安全鉴定、专业施工方案、当地审批或现场安全交底。

详细条文适用边界和南京、无锡、苏州清运规则核查记录见[专题来源笔记](../references/topic-source-notes.md)。

## 拆后验收重点与检查方法

| 检查项 | 怎么检查 | 合格/放行证据 |
| --- | --- | --- |
| 拆除边界和数量 | 对照已签拆改图逐面核对房间、墙面方向、起止点；记录保留的墙垛、门垛及设备口 | 无擅自扩大拆除；实测变化写入更新图/变更记录并双方确认 |
| 结构与异常构造 | 清除浮灰后目视梁、柱、楼板、结构连接和洞口边；检查有无新露钢筋、混凝土缺损、深裂缝、异常变形 | 无未处理的疑似结构问题；疑点有专业意见、方案/手续及完成记录 |
| 管线、烟道和保留设施 | 对照拆前照片逐一检查可见管道、线盒、阀门、立管、烟道、门窗及检修口；有专业测试要求的由相应人员完成 | 无新增破损/堵塞；损伤已修复并按对应专业要求测试/复验 |
| 保留边缘和基层 | 清走垃圾后观察裂缝、松动、空鼓、尖锐残块和局部脱层；轻触/轻敲仅作表层筛查，不在未知构件上重击 | 无可能掉落的松动物；需要修补/加固的范围已标记并纳入03阶段确认，不被直接覆盖 |
| 尺寸和后续接口 | 用卷尺量墙位、洞口宽高、门垛、通道、预留和局部高度；从约定基准面量到面，至少复核两端/关键控制点 | 实测值写回当前版图纸；与门窗、柜体和设备冲突已解决或标待复尺责任/时间 |
| 垃圾和公共区域 | 清点室内/暂存点余量，走查搬运路线、电梯、楼道和物业指定点；核对预约/交接或费用凭据 | 建筑垃圾按本地规则交接；公共区域清扫完成；剩余垃圾和待办项如实记录 |
| 粉尘及现场状态 | 清理后检查地漏、窗槽、设备箱和相邻空间是否进灰，检查保护层是否破损 | 管口继续封闭，保留面保护恢复，现场无影响下一工序的碎块/粉尘堆积 |

### 业主现场检查工具和记录

准备确认版拆改图、卷尺、记号贴、手电、手机和垃圾交接记录。按“全景定位 → 边界/异常近景 → 带尺读数 → 复验后同角度照片”拍摄。不要用普通小锤敲梁柱、剪力墙或不明构件来证明结构安全；疑似结构问题留给专业人员核查。

## 整改、复验与放行03阶段

- 出现超范围拆除、结构疑点、管线损坏、邻接裂缝、堵塞或清运遗留时，登记编号、位置、发现时间、照片、责任方、处理期限和停工范围；不能用“后续抹灰覆盖”关闭问题。
- 复验时核对修复方案和相应测试/专业意见；在同一位置、同一角度复拍并记录尺寸/测试结果。与结构、燃气、电气、给排水相关的问题由相应专业人员确认，不由业主目测代替。
- 拆后尺寸或墙位改变时，更新当前版图纸，通知03阶段进场工人及门窗/定制等相关方；任何需要新增拆改的内容先走书面变更。
- 保留拆前/过程/拆后照片、确认图纸、物业记录、材料/设备保护记录、垃圾清运凭据、异常整改和复验单。

**放行条件**：约定拆除范围已完成、垃圾按本地要求清运、公共区域恢复、管口保护有效、保留结构和管线检查完成、异常问题复验闭环、拆后尺寸已签认，你书面确认后才进入03阶段。若与工人约定阶段付款，按双方确认的可验证节点支付，不以“砸完了”自动等同验收通过。
