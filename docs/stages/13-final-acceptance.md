# 13 整体验收、整改与交付

[上一阶段：开关、灯具、洁具与设备](12-fixtures-and-equipment.md) · [返回整体流程](../00-process-overview.md)

[打开本阶段一页式现场清单](../checklists/13-final-acceptance.md) · [打开完整交付模板](../templates/08-final-handover.md)

## 阶段目标：把“看起来做完”变成可验证、可追责、可结算的交付

最终验收不是一次走马观花，也不等于只看墙面和保洁。业主按合同逐项核对工程范围、材料和质量，按房间与系统完成外观、功能、安全和资料检查；问题编号整改、按原方法复验；未完成事项、保修联系人、设备账户、钥匙及最终结算书面交接。

你是自己购买材料、直接找工人施工的业主，不需要为了验收当然地再找一个“施工方责任人”或监理。建议由你指定一位现场记录/联络人，但验收、整改和结算分别对接实际供货人、安装工人及专业服务人员。谁供货、谁安装、谁接电/接燃气、谁承诺售后，要能从订单、聊天记录、付款凭证和调试单看出来；不能把不同人员混称成一个没有明确身份的“施工方”。

## 什么时候开始：各单项测试完成，但问题还看得见

- 01—12章要求的停检、测试、隐蔽记录和整改已完成；13章不替代水电封槽前、防水覆盖前、吊顶封板前等过程验收。
- 所有工人/安装服务已完成各自工作并清走大件包装，现场可以看清墙地、收口、柜内接口和设备铭牌；保留保护膜到可检查时再逐步揭除。
- 设备有电、有水、有网络或具备厂家规定的调试条件；专业调试预约完成。燃气调试、电气拆检、结构安全判断不安排业主自己操作。
- 订单、施工范围、报价、增减项、材料清单、上一阶段验收记录和付款凭证放在一处；尾款节点和未完项目处理按双方签署/确认的合同或订单执行。
- 准备平面图/房间编号、手机/相机、卷尺、手电、纸巾、插头负载（仅作功能检查）、问题表和蓝色易擦标记。激光仪、绝缘/接地测试仪、燃气检漏工具等由专业人员使用。

## 先明确验收依据：标准、设计、合同、产品说明各有职责

1. **强制法律法规/强制性工程建设规范**：适用范围内必须遵守；它们不是所有既有住宅局部装修项目都自动对应完整新建工程竣工验收程序。出现安全风险或公共设施时，先按主管部门、物业和专业单位要求处理。
2. **适用的国家/行业/地方质量验收标准**：用于相应分项和检测方法。验收标准的产品类型、工程范围、抽样方法和测量工具都要相符，不能从一条不相关的标准抄一个数值。
3. **设计图纸、确认样板、产品技术说明和安装要求**：决定本户型号、安装条件、功能、颜色、尺寸接口和养护方式；设备说明书不替代国家安全要求。
4. **合同/报价/订单/变更单**：把项目范围、材料型号、工艺、验收结果、付款节点和返修责任落到具体交易关系中。没有事先约定的装饰效果，应先协商确认样板或处理方案，不临场创造“行业统一误差”。
5. 江苏住宅可参考推荐性地方标准`DB32/T 3706-2019《住宅装饰装修质量规范》`；推荐性标准是否纳入本户合同、如何用于验收，要按适用条目和双方约定确认。

## 验收顺序：先资料和安全，再系统和房间，最后结算

建议分三轮完成，避免走一圈就签“全部合格”：

### 第一轮：资料核对和安全筛查

先看合同/订单范围、变更、隐蔽验收、材料标签和测试记录；找出尚未调试、被遮挡、暂时不能测试的项目。检查漏水、焦糊气味、裸露电线、松动吊柜/灯具、明显结构裂缝、燃气异味等安全/损害风险。发现时先停止使用或关闭对应系统，联系相关专业人员，不进入普通外观打分。

### 第二轮：逐房间检查外观和操作

从入户顺序走客餐厅、厨房、卫生间、卧室、阳台/设备区。每个问题在现场平面图定位，照片含全景方向、缺陷近景和测量参照；每个设备实际操作，不能只看指示灯亮。

### 第三轮：逐系统联测和问题销项

分别检查电气、给排水、防水/排水、照明、门窗、地板/柜体、空调/新风、家电/网络。对跨房间或同时运行才出现的问题安排联测。所有问题留在清单中，整改完成后按原方法复验并填写日期/结果；不能因为复验完成就删除原问题记录。

## 先把问题分级：哪些立即停用，哪些可列期限

| 等级 | 典型问题 | 处理方式 |
|---|---|---|
| A 安全/持续损害 | 燃气异味、插座/配电异常发热或跳闸、漏水持续扩大、吊挂件松脱、排烟倒灌、疑似结构性裂缝 | 立即停用/隔离对应设备或区域；安全可达时关闭水电气源；联系燃气、电工、结构或相关专业人员。未经复验不得使用/覆盖 |
| B 核心功能/防水失效 | 排水倒坡/倒灌、洁具漏水、设备无法完成主要功能、门窗渗漏、地板松动起拱、检修阀/设备被封死 | 写明位置、设备型号、测试方法和失败现象，约定责任人与修复期限；修复后重做原测试 |
| C 观感/安装缺陷 | 漆面污染、瓷砖崩边/空鼓、门柜划伤、收口不齐、色差、五金异响 | 对照样板、合同或对应验收依据确认；标缺陷范围，约返修或更换方式并复验 |
| D 资料/使用交接 | 缺少回路表、产品序列号、说明书、保修联系人、账号或余料 | 未影响安全的可列交接遗留项，但要明确交付人、材料/文件名称、截止日期和是否影响对应付款 |

不要为了“当天验收完”把A/B级问题写成“入住观察”。观察项应写明持续时间、观察位置、触发条件、报告联系人和若恶化时的处理方式。

## 逐项怎么验：现场观察与专业检测分开

### 水、电、燃气和环境安全

- **用水与排水**：逐个打开龙头/角阀，查冷热、流量和接头；台盆/水槽蓄水后排放，坐便器按说明多次冲水，淋浴区/地漏持续放水。检查柜内、台面下、洁具底座和楼下/相邻可观察区域，干纸巾擦接头辅助找微渗。把发生时间、点位、阀门状态和照片记下。漏水先关对应阀门，查明接头、排水、防水或器具问题，修复后重复相同测试。
- **电气**：业主逐个核开关控制对象、插座面板、照明和常用设备功能，并核配电箱回路标签。保护接地连续性、插座极性、绝缘/漏电保护等需要的测试由电工用适用仪表完成并留测试点/仪表/结果记录；试电笔、手机充电器或“灯能亮”不能证明安全。出现焦味、火花、发热、异常跳闸，停用相关回路并找电工，不能反复合闸。
- **燃气**：业主观察灶具/热水器型号与气源匹配、烟道/通风和操作说明交接；检漏、点火和排烟调试由当地燃气经营单位或有相应能力的服务人员完成并出具/留存记录。闻到异味时不操作电器开关、不用明火，按当地应急指引撤离并联系燃气抢修；不自行拆机或明火检漏。
- **室内环境**：嗅觉、消费级仪器和自测盒不能替代规范检测，也不能根据“无味”推断合格。先核对板材、涂料、胶等材料资料和通风情况；如果要做正式检测，先与检测机构书面确认采用标准、检测目的、项目、房间状态、封闭/采样条件、点位、方法、报告资质和不合格复测方案。`GB 55016-2021`、`GB 50325-2020`和`GB/T 18883-2022`的适用对象、采样条件和判定目的不同，不能混用限值或把一次检测说成“绝对无甲醛”。

### 墙面、顶面、瓷砖和地板

- **墙顶面**：正常自然光和约定使用照明下看裂缝、起皮、掉粉、漏涂、透底、色差、污染及阴阳角/灯槽/检修口收口；重点墙用靠尺、塞尺按约定标准/等级量测并记录工具、位置和偏差。极端侧光可以帮助找施工痕迹，但不能脱离合同等级和标准直接判所有阴影不合格。
- **瓷砖**：等到适合敲击的养护条件，用空鼓锤轻敲按墙/地面区域覆盖，重点检查边角、开孔、门口、管根、地漏周边；用可移除标记编号和拍照。按适用标准、空间部位、集中程度判定，不套用全屋统一百分比；淋浴/阳台等有排水要求处做适量连续放水，观察是否流向地漏、门口有无外溢、是否留明显积水，并确认08章涉水区域第二次蓄水记录。
- **地板**：按实木/实木复合/强化/PVC及浮铺、胶粘、龙骨系统分别检查板面、拼缝、起拱、翘边、行走异响、墙边伸缩、门口过渡和踢脚；地板含水、平整度等依据取自对应产品/铺装标准和实际安装记录，不拿不同仪器和不同地板体系横比。
- **门窗**：逐樘操作锁闭、开启、限位和纱窗；看玻璃/型材/门扇损伤、密封条和排水孔。若外窗工程包含在合同内，按其产品和安装约定用适当淋水/运行观察，不从室内随意向高层外窗泼水制造安全风险。

### 柜体、洁具、照明和设备

- **柜体/门/台面**：逐一开关门扇、抽屉、拉篮，查五金、松动、碰撞、封边和划伤；确认插座、阀门、检修口、滤芯和电器散热空间可操作。查看台面拼缝、开孔/支撑；水槽密封达到厂家规定固化时间后试水，柜内干纸巾复查。
- **洁具**：马桶、台盆、花洒、地漏依12章对应方法进行通水/排水和冷热检查；出现底座渗水、返味或排水异常，拆查原因而非只在外圈多打一圈胶。
- **照明/电器**：开关逐个对控制清单，灯具检查闪烁、异响和固定；设备完成厂家要求的完整运行/进排水周期。多台大功率设备联合测试前由电工/设备人员选择安全组合并观察回路是否异常，不让业主自行人为过载。
- **空调/新风/地暖/智能**：按正常模式测试冷热/换气/温控、冷凝水、滤网和检修可达性；模拟网络中断和断电恢复，确认本地基本控制；专业调试项目留服务单和设定值。

### 网络、账号和安全交接

逐个测试有线网络端口和常用无线区域；核对门锁、网关、传感器、窗帘和场景的管理账号、设备绑定、重置方式与备用机械钥匙。交付前由业主本人登录并确认账户已转移/绑定，安装人员不应保留唯一管理员权限。保存设备型号、MAC/序列号等必要资料时注意账号密码等敏感信息不要发到公开群聊。

## 问题清单如何写：一个问题一条，整改前后能对得上

每条至少包含：

| 字段 | 怎么写 |
|---|---|
| 编号与位置 | `B-厨房-水槽柜-冷水角阀`，房间/墙向/设备名称能唯一定位 |
| 现象和证据 | 写实际观察：如“通水10分钟后纸巾在软管螺母处湿”，附全景、近照、日期/视频 |
| 验收依据 | 指明合同条款、确认样板、产品说明或适用标准的项目；不清楚时先记录争议，不自造标准数值 |
| 责任接口 | 供货/运输/安装/电工/燃气服务/业主使用调试哪一环待确认；不要未经证据先武断归责 |
| 整改计划 | 具体修复或更换什么、由谁做、何时完成、是否涉及拆砖/补漆/恢复防水 |
| 复验方法 | 原测试如何重复、观察多久/什么结果算通过、谁见证/提供记录 |
| 付款/状态 | 未开始、整改中、待复验、通过或按书面协议保留金额；注明协议来源，不口头删项 |

避免“墙面修一下”“卫生间有问题”“工人再看看”等不能验收的描述。完整问题表可直接用[交付模板](../templates/08-final-handover.md)，每次更新保留版本和双方确认记录。

## 整改与复验：先定修法，修完重复原测试

1. 把全部问题逐条编号，区分安全/损害、核心功能、观感和资料项；安全及持续漏水优先停用处理。
2. 与实际供货人或安装人确认责任、修复范围、材料/型号、工期、成品保护和费用。若责任有争议，保存原状、订单版本、照片和测试记录；未商定前避免先拆除或修补破坏证据。
3. 整改前对周边瓷砖、墙漆、柜体、地板和设备做好保护；拆改涉及防水/电气/燃气时，按对应专业工序复验，不能只验表面恢复。
4. 整改后按原问题单中写明的测试方式复验：水渍问题重做通水/纸巾检查；跳闸/接地问题由电工重测；门柜复调后全开全关；瓷砖/地板更换后按适用养护时间再验；环境检测异常时按机构建议查源、通风/治理后重测。
5. 记录复验人、日期、结果和照片；新损伤另建问题编号。暂无法完成的项目列明责任人、期限、影响、临时措施和对应付款安排，双方书面确认。

## 资料交付怎么收：按房间、系统和产品建档

- **合同与结算**：最终合同/报价、变更增减项、工程量或数量确认、收付款凭证、遗留问题及处理协议。
- **现场与隐蔽**：最终平面及水电回路/给排水图、墙地面定位尺寸、吊顶/柜内检修照片、阀门和检修口位置图、隐蔽验收和复测记录。
- **材料与产品**：主辅材品牌、完整型号、规格、生产者/批次、发票/订单、CCC核验（适用时）、报告、色号/封样、剩余同批瓷砖/地板/涂料及备用五金。
- **设备与账户**：铭牌/序列号、使用说明、安装/调试单、滤芯型号、保修期限和联系人、网络/智能设备管理员转移和重置方法、钥匙/门禁。
- **专业测试**：电工测试记录、给水试压/排水测试、防水闭水与淋水记录、设备通水通电/燃气调试服务单、需要时的室内环境检测报告。
- 纸质材料可拍照备份；电子文件按`房间-系统-日期-内容`命名。保修电话和紧急关水/断电/燃气阀位置另做一页，放在家庭成员都能找到的地方。

## 结算与交付：按合同节点办，不用“签了验收”抹掉未完事项

- 对照合同逐项核完工数量、增减项、已供材料和已支付金额，结算只计双方确认的范围；口头增项或取消先查记录，金额未确认时列明争议和暂缓部分。
- “外观签收”“单项功能测试”“阶段验收”“遗留项结清”“最终交付”和“尾款支付”是不同节点。最终签字如有未完成事项，附件逐项写明问题编号、金额/付款安排、责任人和期限，不签与现场事实不符的“全部无质量问题”。
- 付款条件/质保金或遗留款按合同及双方书面补充协议执行。若合同没有明确约定扣款方式，不擅自推定可以单方面扣除任意金额；先通过书面协商确定整改期限、对应款项和争议处理方式，必要时咨询当地消费者组织/市场监管部门/法律专业人士。
- 质量保修起算点、范围、响应时间和耗材/人为损坏除外条款，以合同、产品保修文件和现行法规的适用要求核对；让实际供货/安装服务人分别写明联系人。不是所有设备都由装修工保修，也不是拿到厂家质保就自动包含安装质量。
- 钥匙、门禁、设备账户、余料、工具、使用说明和紧急阀门位置交接后，双方留存同一版签字/确认记录。遗留项目完成后再追加销项和复验记录。

## 入住前等待与室内环境检测

没有对所有装修住宅通用的“通风X个月就能入住”期限。涂料、密封胶、柜体等先满足具体产品养护/通风要求；房间无持续渗漏、潮湿和霉变；家具、窗帘等主要污染源实际进场后，再根据家庭成员风险与检测目的决定是否检测。

委托检测前要求机构书面说明：采用GB 55016-2021、GB 50325-2020还是GB/T 18883-2022中的哪一项及原因；检测项目和限值对应哪项标准；装修/家具完成状态、房间关闭条件、采样点/时间、采样前设备运行状态、实验室资质和报告范围；结果不符合时如何复测。三者用途、适用对象、封闭和采样条件不同，数值不能直接比较。手持仪表或自测盒可以提示异常，不能冒充有资质机构的标准检测报告；空气检测也不能代替查找板材、胶、潮湿或通风等污染源。

入住早期继续巡查柜内水迹、地板起拱、门窗渗漏、墙顶裂缝、异味/霉变、排水返味、配电异常和设备噪声。发现问题先拍照、停止扩大损害，按保修联系表书面通知对应供货/安装人并保存回复。

**最终放行条件**：合同范围和变更核对完成；安全、漏水、排水、主要功能和明显观感问题已整改复验；必要的专业测试记录齐全；未完成事项、责任人、期限和付款安排已有书面约定；设备、钥匙、账号、图纸、材料资料和保修联系人已交接。业主确认后按合同约定结算和交付。
