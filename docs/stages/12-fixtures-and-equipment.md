# 12 开关、灯具、洁具与设备

[上一阶段：门、柜体、台面与地板](11-doors-cabinets-and-flooring.md) · [返回整体流程](../00-process-overview.md) · [下一阶段：整体验收、整改与交付](13-final-acceptance.md)

## 阶段目标：每个末端都能安全使用、便于断开和检修

本阶段把前期预留的电源、给排水、排气、网络和固定位置接成可用系统，主要包括开关插座、灯具、洁具、水槽龙头、热水器、厨卫电器和智能控制的末端安装、单机调试和联合测试。结束时应做到：型号与预留匹配；电工完成规定的电气测试；用水点通水、排水顺畅且接口无渗漏；燃气类由对应专业服务人员安装调试；设备说明、序列号和质保资料齐全。

空调、新风、地暖、燃气管线等可能已在04/05/09章施工。本章验收这些系统的末端连接、控制和交接，不代表允许装修工改动公共管线或替代设备厂商/燃气专业人员调试。业主负责核型号、看记录、做非破坏性功能检查；带电测试、配电箱操作、燃气检漏和拆机必须由相应专业人员完成。

## 进场条件：对照设备清单、隐蔽图和现场实物

- 11章柜体、台面、门和地板已安装并完成成品保护；开关插座、灯具、洁具安装位置按最终完成面复核。
- 05章回路表、给排水图及隐蔽验收/测试记录可查；09章灯位、吊顶加固、检修口和设备接口已交接；04章空调/新风接口及排水记录可查。
- 逐件设备清单包含房间、品牌/完整型号、额定电压/功率、尺寸或安装模板、插头/接线、进排水、排烟/散热、控制方式、安装责任方和质保联系人。
- 燃气器具使用的气种、当地供气类别、燃气接口和安装位置已让燃气经营单位/品牌服务核对；燃气阀门、管道和烟道条件未确认不安装、不点火。
- 卫生间的等电位、插座保护、浴霸/电热水器回路及湿区设备位置由电工对照设计和现状确认；不能因换面板、装浴室柜而拆掉保护或遮盖测试点。
- 各设备配套安装附件、纸质/电子说明、设备铭牌和安装模板到场；打孔位置避开05隐蔽图标注的管线、防水区域及结构禁钻区。

## 工作范围：末端安装与调试，不重复做隐蔽改造

通常包括：开关插座、照明灯具、智能面板/控制器安装；马桶、台盆、浴室柜龙头、花洒、地漏和水槽附件连接；热水器、烟机、灶具、洗碗机、洗衣机、净水器等按产品责任方安装；末端电气与给排水接驳；逐件功能测试和整屋联合运行。

下列内容必须另行确认责任和计价：新增/改造回路与配电箱、墙内开槽和穿线；移动或拆改燃气管道、公共立管、排烟道、消防设施；拆砖重做防水、改变地漏/排污口；设备开孔、台面返工、烟道扩孔、柜体改造；吊灯加固和特殊支架；厂家安装费、上门费、超距接管、旧机拆运、耗材/滤芯、调试和保修边界。

设备本体、辅料和安装往往由不同商家提供。合同或订单要标明：谁供货、谁安装、谁提供角阀/软管/密封圈/止回阀/电源线/支架、谁负责漏水或设备损坏、谁出调试单及售后。主机品牌不能替代附件规格和施工责任。

## 到货怎么验：逐件核铭牌、型号、附件和认证范围

拆包前拍摄外箱四面、封口和运输状况；对照采购订单、送货单、铭牌/机身标签、说明书及合格资料。关键字段是准确品名、完整型号、规格参数、制造商及实际生产地址、生产日期/批次或序列号、执行标准、适用电压/功率/气源、包装配件和数量。销售公司、仓库地址不等于生产工厂。CCC只按目录具体品类要求，核证书状态和证书对制造商、生产厂及型号的覆盖，不因同品牌其他型号有证就推定本机有证。

| 产品 | 到货具体核对 | 不符时处理 |
|---|---|---|
| 开关、插座 | 系列完整型号、额定电压/电流、插孔规格、颜色、面板/底盒适配、生产者、CCC（目录适用时）、数量；USB/智能模块与常规插座分开核 | 规格、电流或型号不符先隔离；不要仅凭外观相似安装。让供货方补证或换货 |
| 灯具、驱动和控制器 | 灯具型号、输入电压/功率、色温/显色参数（订单约定时）、安装方式、防护等级/适用环境、驱动型号、调光/协议兼容性、CCC目录适用性 | 缺驱动、配件或参数不符先不装；不同批次/色温先同场点亮样灯对比。按当前规则核证，不只看CCC图标 |
| 陶瓷洁具 | 型号、排污方式和坑距适配、颜色、冲水组件、进水配件、座圈、固定件、外观和出厂资料；智能坐便器另外核电气参数和CCC适用性 | 裂纹、缺口、釉面损伤或排污方式错误先拍照并隔离，未安装不签最终验收 |
| 龙头、花洒、角阀、软管 | 具体型号、冷热标识、接口螺纹和尺寸、软管长度/压力适用范围、阀芯/过滤件、密封垫、生产者和执行标准 | 缺垫圈、牙型不合或软管受损不以缠带强行凑接；先确认接口兼容并补齐原厂件 |
| 电热水器/燃气热水器 | 型号、额定功率/电压或气种/额定参数、容量、排气方式、CCC适用性、附件和安装要求；生产/序列号与保修渠道 | 气源、排气方式、回路或墙体条件不匹配立即停装，不用转接或改喷嘴自行适配 |
| 烟机、灶具、洗碗机、洗衣机、净水器 | 型号铭牌、开孔模板、插头/功率、进排水、排烟接口、安装净距、随机配件、CCC目录适用性和质保 | 先把设备模板与柜体/台面图对照；错孔或接口不足时停装，不现场扩大孔洞后再追责 |

**包装签收≠安装验收。**可在送货单写“已收X件，外包装/可见外观核查，安装接驳、通电通水与功能测试未完成”，附可见异常。保存包装标签、序列号、发票、说明书和易丢小配件；争议件不安装、不丢包装、不自行拆机。

### CCC怎么判断：看目录类别和准确型号，不搞“一律3C”

插头插座、固定式开关、部分灯具和家用电器/燃气器具可能属于CCC目录，但产品边界按当日目录和界定表判断。采购时在国家认监委/认证机构官方查询渠道查证书状态、认证委托人、生产者/生产厂、产品名称型号及认证单元；证书截图与包装型号一并归档。CCC是目录产品市场准入认证，不证明这件货没有运输损伤、安装正确或适配本户回路。

灯具CCC实施规则刚更新：认监委2026年第22号公告规定新旧规则至2026-12-31并行，2027-01-01起按新版规则实施；既有有效证书可继续使用。应按具体灯具是否落入目录以及证书有效状态核对，不把本次规则切换误解为所有灯具都突然必须新证。

## 设备选购和预留：先拿准确型号的安装图

### 开关、插座与智能控制

- 按回路表确定普通插座、空调/电热水器/厨房等大功率设备的供电方式和独立回路需求；额定电流数字不是允许业主自行换大断路器的依据，导线、保护器和负载由设计与电工核算。
- 插座按实际电器插头、插头朝向、柜体/台面遮挡和拔插空间选型；厨房、卫生间、阳台等潮湿/溅水位置，按现行规范区域和保护措施布点。插座面板标“防水”不能替代区域设计、漏电保护、接地和防溅盖适用条件。
- 智能开关采购前确认零线/火线需求、负载类型、最小负载、调光方式、网关/协议、断网基本操作、断电后状态和后续替换能力。智能灯泡与传统调光器、电子驱动不一定兼容，先拿实际型号做样机测试。
- 开关功能按房间/灯位写入控制表，双控、多控、场景键和智能联动注明默认逻辑；不要仅用“主灯/灯带”标记无法唯一识别的回路。

### 灯具、灯带、浴霸和排气扇

- 灯具的色温、显色、亮度和眩光感受与房间用途、墙地颜色、灯具光学结构有关。先在同一房间点亮实际样灯；同一可视区域尽量按订单确认一致色温/显色等级和调光方式，避免只按包装上的“暖白/自然光”名称猜效果。
- 确认灯具重量、安装方式、开孔尺寸、散热和驱动/电源检修位置。吊灯、轨道和大型灯具的锚固须接到已确认的承载基层/加固件，不可只挂石膏板或薄龙骨；开孔前核对09章吊顶图和龙骨位置。
- 灯带要确认灯带电压、功率/米、总长度、驱动额定输出及余量、线路压降和散热槽构造由设计/安装方匹配；驱动留可更换检修位置，不能封死在柜体或吊顶里。
- 浴霸/暖风机需核风暖/灯暖类型、电源回路、吊顶开孔和独立固定、换气管路/止回、检修空间；湿区安装位置与防护等级按设备说明、现行电气规范及设计核定。不要自行更换更大功率机型而不核回路。

### 洁具、龙头和卫浴附件

- 坐便器按**准确型号安装图**量坑距（排污中心至完成墙面的测量基准由厂家图确认）、排污方向、墙排/地排、角阀位置、插座和智能盖板电源。毛坯中心线或商品页的通用尺寸不能代替砖完成后实测；密封圈/法兰、固定件按产品配套，不靠多层偏心件硬改。
- 台盆/浴室柜核台盆开孔、龙头孔、墙排/地排、冷热水角阀、柜门/抽屉避让和检修路径；台上盆、台下盆和一体盆的固定与密封方式不同，按台盆/台面说明安装。
- 龙头/花洒核冷热方向、墙出水口中心距和深度、螺纹接口、装饰盖覆盖范围、软管长度及热水器最低/最高工作条件。恒温花洒若要热水器稳定供热，确认水压差、进水温度和最小启动流量要求；不匹配时不是换一个花洒芯就一定能解决。
- 地漏、水槽、洗衣机排水等按对应存水弯/防臭构造和排水系统检查；不要把多个软管松散插在地漏里或堵住通气构造。台盆、水槽和墙边用与基材相容的密封材料，做好干燥、粘结和养护。

### 热水器、燃气灶及厨房/洗衣电器

- **燃气灶、燃气热水器：**先核铭牌气种、产品安装方式、排烟/排气要求、安装位置和当地供气条件。器具安装、燃气软管/管道连接、检漏与点火调试交由燃气经营单位或依法具备相应服务能力的安装人员；装修工和业主不得改公共管道、改喷嘴、用明火检漏或封闭设备要求的通风。索取安装/检漏/调试单并保存设备序列号。
- **电热水器：**安装前由电工核回路、接地、剩余电流保护、插座/隔离方式与设备功率；墙体承载、挂架和检修净距由安装人员确认。首次通电前按说明先注满水并排尽空气，确认无漏水后再供电；禁止空胆通电。试温后检查冷热接口、泄压/排水部件和柜内/墙面水迹，不自行堵塞安全泄压口。
- **烟机/集成灶：**实际开孔与烟道接口按准确型号图核对；确认烟道止回阀方向、密封、排烟管无压扁/脱落、检修/清洗可达，并与橱柜门板和燃气灶位置协调。不得封堵公共烟道或擅改共用设施；运行时用纸巾观察吸风仅作功能筛查，不能替代风量检测或烟道合规判断。
- **洗碗机、洗衣机、净水器：**确认专用插座可断电、角阀可关、进水管不扭结、排水管固定高度/走向符合说明、滤芯和检修件能取出。洗碗机首个完整程序、洗衣机进排水/脱水、净水器冲洗排废都按厂家首次使用步骤完成；柜体内铺干纸巾检查接头渗水，漏水保护/止水阀按说明试验。
- **空调、新风、地暖末端：**本阶段检查面板/温控器、风口、冷凝水和已交接系统的运行，不替代04/09章的安装调试；模式、风量/温度、冷凝水排放、滤网/检修可达性与安装方共同确认并记录异常。

## 安装顺序：先检查接口，再安装；先做一件样板，再批量

1. 到货逐项开箱验型号和附件；有裂损、漏件、认证/供电/气源不明先隔离。
2. 将设备模板与完成面、柜体图、05隐蔽图逐点叠合，记录插座、阀门、排水口、孔位和检修空间；不一致先书面定变更。
3. 打孔/固定前由安装人复核水电及防水记录；无法确认管线或基层承载时停止施工并请对应专业确认。
4. 先安装一个同类型样品（一个开关回路、一盏灯、一个洁具/台盆或一台设备），检查安装高度/方向、收口、操作和检修空间，业主确认后继续同类安装。
5. 按产品说明连接；水路先干装对口再密封，电气由电工接线，燃气由专业服务人员处理。接口被装饰盖、柜体或设备遮住前拍照并做可见检查。
6. 单件安装完成即做对应功能测试；不得等所有设备装完才发现坑距错、极性错或水路漏水。
7. 全屋设备完成后按回路/房间/设备组联合运行，记录异常、整改责任及复测结果，再交13章整体验收。

## 常见问题和偷工减料信号

| 现场表现 | 可能原因/风险 | 业主怎么处理 |
|---|---|---|
| 插座“有电”但保护/接线未经检测 | 相线/中性线/保护接地接错或PE/漏保失效，存在触电风险 | 不自行拆面板；停用该回路，请电工用合适仪表测试并给记录，复测通过才使用 |
| 卫生间插座被镜柜/花洒溅水，或保护装置被取消 | 点位与湿区、设备空间不匹配 | 先断开相关回路，要求电工按湿区范围、保护措施和设计重新核定，不能只加防溅盒了事 |
| 灯具频闪、嗡鸣、同型号明显不同色 | 驱动不兼容/批次不同/调光方式不匹配 | 对照型号、驱动和批次；现场换接或退换前先由电工断电检查，不在通电状态拆接 |
| 吊灯/浴霸只固定在面板或薄龙骨 | 缺少可靠承载路径，可能坠落 | 立即停止使用，卸除负载；依据09加固记录由安装方整改并拍照，不让业主做悬挂测试 |
| 马桶靠偏心件、厚胶才能对上排污口 | 坑距/排污方式测错、瓷砖完成面偏差或型号不符 | 不封底座、不打胶，复测排污中心和型号图，先解决错配再安装 |
| 龙头/角阀接口渗水后反复缠胶带或打胶 | 螺纹/垫片不匹配、密封面损坏或过紧 | 关阀、擦干，拆检由安装人换正确配件；干纸巾复测无水迹后再封闭柜体 |
| 热水器未注水就通电，或燃气器具由普通装修工接管 | 可能干烧、漏气/排烟风险及责任不清 | 立即断电/关阀；通知品牌/燃气专业人员检查，保留安装调试单，不自行复位点火 |
| 烟机排烟管压瘪、未接牢公共烟道或被柜体封死 | 排烟效率下降、油烟回流且难检修 | 暂停使用，要求按设备说明和物业/烟道规则重装，检查止回阀、接口和检修空间 |
| 洗衣机/洗碗机运行时柜底湿、排水倒灌 | 管路扭结、接口松动、排水走向/防臭结构不合 | 关水停机，拍摄漏点并检查完整运行周期；修复后重新运行并复查纸巾/柜底 |
| 智能设备断网/断电后关键照明无法控制 | 基本操作过度依赖云端或网关 | 要求测试断网/重启、物理开关和本地控制；不能满足的设备调整方案或保留常规控制 |

## 开工前问清这些事，并写进安装单

1. 这个准确型号的安装图、开孔图和接线/接口参数在哪里？谁负责按完成面复尺？
2. 设备的额定功率/电流、供电方式和所需回路是否与05章回路表相符？谁是接线和测试责任电工？
3. 插座、灯具、浴霸和热水器是否落入CCC目录？证书覆盖哪个型号和生产厂？
4. 卫生间湿区设备/插座位置、PE接地、剩余电流保护和等电位由谁核验，如何形成测试记录？
5. 坐便器准确坑距、台盆/龙头接口、冷热方向、花洒最低工作压力和地漏防臭方式是否与实物匹配？
6. 燃气器具由哪家燃气/品牌服务人员安装，气种和排气条件由谁核实，是否提供检漏/调试凭证？
7. 洗碗机、洗衣机、净水器的进排水和防漏保护如何安装；柜体内怎样留关阀、断电和换滤芯空间？
8. 任何打孔或移位是否触及防水/隐蔽管线？费用、恢复防水和瓷砖的责任怎么约定？
9. 哪些辅料由谁提供，品牌/型号是什么？保修由主机厂家、安装方还是供货商承担？
10. 每件设备的单项测试、等待条件、全屋联合运行和尾款放行证据分别是什么？

## 等待与停检点：按固化、测试和专业交接放行

- **拆箱和安装前**：型号、附件、CCC适用性、气源/功率和接口核验通过；异常品不安装。
- **开孔、打孔和固定前**：核对完成面、隐蔽图、防水和承载基层；位置不明不施工。
- **接口被遮挡前**：插座接线、软管/阀门、排水、设备铭牌/序列号拍照；做可见检查后再装盖板/封柜。
- **密封材料固化后**：台盆、马桶周边、水槽、龙头底座等按对应产品说明等待，再做通水和纸巾查漏；固化时间随材料、温湿度和缝宽而变，不统一写死几小时。
- **燃气设备启用前**：燃气专业安装人员完成气密/点火/排烟等适用检查并交付记录；未经交接不点火、不使用。
- **电热水器首次通电前**：按说明注满水并排气、核漏水和电气条件；任何保护测试由电工做。
- **阶段放行前**：完成逐回路/逐设备单项测试和多设备联合测试，异常整改、复测并留档后进入13章。

## 现场验收怎么查：业主做功能观察，专业测试由专业人员记录

### 开关插座和配电回路

1. 按房间点位图逐个按开关，记录灯具/风机/场景对应关系；双控、多控和智能逻辑逐种操作。
2. 检查插座面板牢固、无破裂/歪斜，插孔无松动；用合格插头轻插拔查看保持力，不用金属物探孔。
3. 让电工用适当仪器测插座极性、保护接地连续性及剩余电流保护动作等适用项目；记录仪表名称/测试点/结果。插座能给手机充电不是接地或漏电保护合格证明。
4. 由电工按回路表逐回路断送电，核配电箱标签与实际控制区域一致；发现跳闸、异味、发热、火花立即停用该回路并排查，不反复合闸。
5. 业主不打开配电箱、不拆带电面板、不用身体接触或低价试电笔替代测试。验收资料标出未测试、故障和复测日期。

### 灯具、风机和控制器

1. 逐盏检查外观、灯罩、固定、安装方向、色温/光色与样灯一致；白天和夜间常用场景分别观察。
2. 连续开关几次并运行实际调光/智能场景，观察闪烁、延迟、异响、自动重启或局部熄灭；频闪争议按产品资料/专业测量判定，不以手机慢动作视频作最终检测。
3. 由安装者确认大型灯具、浴霸/风机支架固定到预定承载基层；检查灯带/驱动电源位置可检修，风管/止回阀接口牢靠。
4. 按正常使用运行一段产品说明允许的时间，观察异常热味/噪声；不触摸裸露电气部分或自行打开驱动。

### 洁具、龙头、排水和热水

1. 开启每个角阀和龙头，冷热方向正确；柜内接口垫干纸巾，观察接头/阀杆/软管端头，保持正常水压后再复查。
2. 台盆/水槽先蓄水到日常合理水位，再一次排放；观察溢水口、下水器、存水弯、软管和柜底。检查盆边/台面接缝是否按产品方法密封。
3. 坐便器按说明多次冲水，观察进水、冲水、排污、底座周边和楼下/邻近处；底座和排污口周围出现水迹或异味立即停用，未查清不能靠外圈打胶遮盖。
4. 花洒/恒温龙头逐档切换冷热和出水模式；检查软管、阀芯、墙出水口和地面排水。水温/流量不稳先查水压、热水器适配和供水，不拆恒温阀乱调。
5. 地漏和淋浴区连续放水，观察排水、倒灌/积水、地漏芯和异味；水封/防臭构造按具体地漏说明核查，不往地漏塞海绵或抹胶封死。
6. 热水器由安装服务按说明完成首启、温度/安全功能和排放检查；燃气机额外取得专业调试/检漏记录。业主只观察界面、温度和异常报警，不自行接燃气或拆安全阀。

### 家电、网络和整屋联合运行

1. 对照设备说明逐台完成首次启动；核序列号、日期/保修激活、滤芯/软管/支架安装和需要留存的首次运行记录。
2. 洗碗机/洗衣机/净水器至少按说明完成适用的完整进水、运行和排水流程；运行前检查阀门，运行时看柜内纸巾和地面，结束后复查接口。
3. 烟机和排风按说明试不同档位，检查烟管/排水/止回接口无脱落、明显漏风；灶具、热水器的燃气安全和排烟测试仅由对应专业人员进行。
4. 智能开关、网关、温控器和遥控设备核对网络断开、路由器重启/停电恢复后的本地控制与默认状态；房屋关键照明不能只依赖远程云端操作。
5. 逐回路打开常用设备组合（由电工/设备安装人员选择安全测试组合），观察异常跳闸、气味、噪声、排水冲突和柜内温升；结果记入设备表并带日期、测试人。

## 整改、成品保护、资料和付款放行

- 漏水：先关对应角阀/总阀，擦干并标记最先出水的位置；查垫圈、螺纹、软管、下水或设备本体。修复后重做同一通水/运行测试，柜内无新水迹才放行。
- 电气：异常回路停用、标记并由电工查因；不得反复合闸、换大断路器或让业主拆装。整改后专业人员重测并提供记录。
- 燃气：闻到燃气异味时不要操作电器开关/明火，按当地燃气应急指引关闭安全阀（仅在安全可达时）、撤离并联系燃气抢修；不自行拆机检漏。安装/点火异常联系燃气或品牌服务。
- 点位不匹配：先对照模板和隐蔽图，评估对瓷砖、防水、柜体、结构的影响，书面确认变更、恢复工艺、费用和责任后施工。
- 返修后按原测试项目复验，不以“已拧紧”“已经试过”替代记录；因拆装造成的防水/饰面破坏同步修复并复验。
- 保存材料采购单、CCC核查记录（适用时）、铭牌/序列号、安装及调试单、质保卡、使用说明、隐蔽照片、回路表、阀门/检修位置图和整改复测记录。包装在退换期和安装验收前保留。
- 清除保护膜前查表面和功能；后续保洁/入住按设备说明清洁，保留滤芯型号、耗材周期、断水断电/阀门位置。燃气与电气设备交付后告知家庭成员基本关断位置。

**放行条件：**型号/附件与订单一致；开关控制逻辑和电工测试记录齐全；灯具/风机固定可靠、可检修且功能正常；洁具、龙头、用水电器逐项通水排水无渗漏；燃气器具已由专业方安装并留交接记录；家电完成约定调试；异常项整改复测完成、成品资料移交并书面放行后进入13章。
