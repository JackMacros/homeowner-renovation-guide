# 材料采购与品牌型号管理

[返回专题总览](index.md)

## 核心原则

材料管理不是“买大牌”，而是建立一条可追溯链：

> 使用位置 → 性能需求 → 材料体系 → 完整型号 → 正规渠道 → 到场验货 → 施工用量 → 剩余材料

品牌只能帮助缩小候选范围，不能代替型号、用途和施工条件。

## 先区分采购责任

### 业主购买

适合价值较高、款式明显或希望控制品牌的主材，例如瓷砖、洁具、门、地板和设备。业主承担选型、尺寸、到货、补货和退换风险。

### 工人或施工方购买

适合用量零碎、与工具工法高度相关的辅材。必须在报价中写清品牌、型号、结算方式和验货权，不能只写“辅料包干”。

### 厂家配套

设备、门窗、定制、暖通等系统宜由责任主体提供配套附件和安装服务，减少主机、辅材和安装互相推责。

## 材料清单字段

每一种材料建议记录：

- 分类和使用区域；
- 品牌；
- 完整产品名称和系列；
- 型号、规格、颜色和表面；
- 执行标准或性能证明；
- 生产批次、色号和保质期；
- 单位包装与采购数量；
- 理论用量和预计损耗；
- 配套辅材；
- 购买渠道、订单和发票；
- 计划到场和实际到场日期；
- 验货结果；
- 剩余材料及保管位置。

## 怎样建立品牌候选池

同一品类可先选择两至四个候选品牌，再比较具体型号：

1. 产品是否明确适用于当前位置和基层；
2. 技术资料和检测信息是否容易获得；
3. 当地是否有正规、稳定的供货渠道；
4. 工人是否真正熟悉该产品，而不是只听过品牌；
5. 辅材和施工工具是否齐全；
6. 补货能否买到同系列、同批次或兼容产品；
7. 安装与售后责任是否清楚；
8. 价格差异是否来自实际性能，而不是营销名称。

不制作脱离预算和地区的永久品牌排行榜。品牌、系列、渠道和服务会变化，具体候选库应注明更新时间。

### 地区、产地与价格的写法

- 本指南案例地区默认江苏；每条价格注明城市/来源期次、规格、计价单位、税费和包含范围。政府工程信息价是计价参考，不是政府定价，也不自动等于家装零售价。
- 产地用于说明产业集群、产品专长和物流条件，不直接当质量结论。比如佛山及广东相关区域是建陶重要产区，但“广东砖”不等于每个品牌、型号、批次都优质；其他建陶产业集群也应按具体品类比较。
- 需要核验包装标签上的生产者全称、生产地址、执行标准、产品型号、批号和等级；订单/发票上的型号必须与实际送货一致。防止用“佛山砖”“广东砖”等口头产地标签替代真实厂名厂址。
- 比较产区直采与江苏本地授权经销商时，把运输、上楼、破损补货、同批次补货、退余砖和售后成本放在同一张总价表中；小面积自装不假设工厂直采一定更便宜。
- 涉及性能与安全的说法，查该产品对应的国家/行业标准、产品检测报告和监督抽查公示；不能把某次抽查结果泛化为整个品牌或整个产区。

## 正规渠道与防伪

- 优先品牌官方渠道、授权经销商或可开具明确单据的商家；
- 订单中保留完整商品标题和型号，不只保存直播截图；
- 到货后核对外包装、标签、批次、数量和封口；
- 防伪码只能作为一项辅助，不代替渠道和产品一致性核对；
- 高价值设备记录机身序列号；
- 对电气、燃气相关产品核对适用的认证和产品资料；
- 不接受没有包装、来源不明的大量分装材料。

### CCC认证怎样看

CCC只适用于当时目录范围内的准确产品类型，且目录会调整。家装中可能涉及电线电缆、开关插座、部分低压电器、灯具、家电、燃气器具以及部分建材，但不能看到“装修材料”就一律要求CCC。

核验时应记录证书编号，并比对证书中的委托人或生产者、产品名称、型号和当前状态。产品上印有CCC图案，不等于证书仍有效或覆盖当前型号。采购时以[国家认监委](https://www.cnca.gov.cn/)和当日目录、查询结果为准。

### 绿色建材认证怎样看

绿色建材认证属于自愿性分级认证，可作为绿色、低碳等属性的参考，但不能代替：

- 法定CCC认证；
- 产品合格证明；
- 性能检验报告；
- 工程进场验收；
- 对品牌、型号、批次和用途的核对。

认证边界及截至2026-10-09的目录说明见[一手来源研究笔记](../references/topic-source-notes.md#五ccc绿色建材和材料证明的边界)。

## 到场验货流程

1. 未拆包前拍摄包装和运输状态；
2. 对照订单核对品牌、系列、型号、规格和数量；
3. 核对生产批次、色号、日期和保质期；
4. 检查破损、受潮、变形、漏液和污染；
5. 抽查附件、说明书和合格资料；
6. 对瓷砖、地板、涂料等关注批次一致性；
7. 验货合格后再签收和允许开封使用；
8. 异常材料单独隔离并及时联系商家。

“物流已经签收”不等于“材料已经验收合格”。

## 用量与损耗

用量应由三部分组成：

> 净施工量＋合理损耗＋维修备用量

损耗受排版、规格、房间形状、运输、施工工艺和包装单位影响，不应对所有材料套用同一百分比。

采购前应让设计、商家和工人分别给出计算依据；差异较大时，先查排版和计量口径。定制色、同批次难补货的材料应预留维修余量，但也要考虑保质期和储存条件。

## 到货时间

### 适合提前确定但不一定提前送货

- 门窗、空调、新风、地暖；
- 瓷砖排版相关材料；
- 橱柜、定制柜和室内门；
- 洁具和嵌入式家电。

这些材料的尺寸会影响设计，需要提前选型，但过早到场容易占地和损坏。

### 适合临近施工到场

- 水泥基、胶粘剂、防水、腻子和涂料等有保质期或储存要求的材料；
- 易受潮、易变形的木质材料；
- 大型玻璃、台面和成品柜件。

## 储存和现场管理

- 防潮材料离地、避水、按要求堆放；
- 液体和化学材料防冻、防晒并保持原包装；
- 瓷砖、板材等防倾倒，避免楼板局部集中堆载；
- 不同批次分区标识，使用前统一确认；
- 已开封材料记录开封日期和可使用期限；
- 余料不得在未确认前由工人随意带走或丢弃。

## 样板与封样

对颜色、纹理和等级容易争议的材料，保留封样：

- 拍摄完整标签；
- 在样品背面写明区域、型号和确认日期；
- 业主与供应方各自确认；
- 到场材料与封样比对；
- 完工后保留一小份维修样品或完整信息。

## 常见采购陷阱

- 低价型号与展示样品不是同一系列；
- 套餐只含基础附件，必要配件全部另收费；
- 品牌正确但型号被降级；
- 计价单位故意模糊，例如延米与投影面积混用；
- 免费安装不包含开孔、搬运、拆旧、辅材和调试；
- 以“升级款”“工程款”等非标准描述替代完整型号；
- 补货批次不同造成色差；
- 线上低价但没有当地安装和售后。

## 材料进场放行条件

- 与合同和订单完全对应；
- 包装、批次、数量和外观检查通过；
- 产品适用于当前基层、区域和施工方法；
- 配套辅材已经到齐；
- 施工方确认会按产品说明使用；
- 异常材料已隔离，不混入施工；
- 验货照片和单据完成归档。
