# 业主验收工具箱

[返回专题总览](index.md)

## 原则

工具用于把问题说清楚和留下记录，不是让业主代替专业检测。先确认工具适合当前项目，再确认操作不会损伤成品或带来触电、坠落等风险。

## 基础工具

| 工具 | 主要用途 | 注意事项 |
|---|---|---|
| 卷尺 | 门洞、点位、柜体和完成面尺寸 | 从明确基准测量并拍下读数 |
| 激光测距仪 | 房间大尺寸和复尺 | 不能代替短距离精细测量 |
| 激光水平仪 | 标高、水平线、墙面和吊顶参考 | 先确认仪器状态和摆放稳定 |
| 水平尺 | 台面、地面、设备和坡向初查 | 短尺不能代表整面误差 |
| 靠尺和塞尺 | 墙地面平整度辅助检查 | 按合同及适用标准判断结果 |
| 空鼓锤 | 瓷砖和部分基层空鼓检查 | 达到养护条件后轻敲，不暴力敲击 |
| 强光手电 | 查看吊顶、柜内和角落 | 不用贴墙极端照明代替正常观感验收 |
| 检查镜 | 查看台盆后、柜体内等死角 | 注意边缘不要划伤成品 |
| 小型内窥镜 | 查看部分孔洞或狭窄空间 | 不随意伸入带电设备和管道 |
| 记号贴、可移除胶带 | 给问题编号定位 | 先确认不会损伤墙漆和饰面 |
| 温湿度计 | 辅助记录施工环境 | 不能单独证明基层已经干燥 |
| 插座测试器 | 对插座进行基础状态检查 | 只能辅助筛查，不能代替专业电气测试 |
| 干纸巾 | 检查接口微小渗漏 | 通水后擦拭角阀、软管和接头 |
| 弹珠或小球 | 粗略观察局部坡向 | 不能替代实际泼水和排水测试 |

## 建议准备的记录用品

- 带时间信息的手机相机；
- 移动电源；
- 图纸和平板或硬质夹板；
- 记号笔、标签纸和编号贴；
- 鞋套、手套、口罩和护目用品；
- 小塑料袋，用于保存标签或材料样品；
- 云端和本地双份备份空间。

## 不建议业主自行操作的检测

- 打开带电配电箱进行拆接；
- 使用绝缘电阻测试仪等专业电气仪器但不懂隔离操作；
- 对燃气系统自行打压或检漏；
- 在高处无防护攀爬检查；
- 随意切割防水层测厚；
- 用破坏性方法检查承重或隐蔽结构；
- 对空调冷媒系统自行放气、加压或拆接；
- 使用明火寻找漏点。

这些项目应由具备相应能力的人员完成，并向业主提供记录或结果。

## 按阶段携带

### 放线、拆改和砌墙

- 图纸、卷尺、测距仪、水平仪、标签和相机。

### 水电

- 图纸、卷尺、相机、标签；
- 插座测试器仅用于完工后的基础辅助检查；
- 打压和专业电气仪器由施工或检测人员准备。

### 防水

- 相机、计时记录、可移除水位标记、手电；
- 检查楼下和相邻墙体所需的联系方式。

### 瓷砖和找平

- 空鼓锤、靠尺、水平尺、塞尺、卷尺、可移除标签。

### 吊顶和墙面

- 激光水平仪、靠尺、手电、相机和图纸。

### 安装和竣工

- 插座测试器、干纸巾、卷尺、手电、问题编号贴和设备说明书。

## 测量记录格式

每次测量至少记录：

> 日期＋阶段＋房间＋位置＋工具＋测量方法＋结果＋照片＋判断依据＋复验结果

只拍一个数字而没有房间、方向和基准，后期通常无法使用。

## 工具误差

- 新工具先在已知平面或重复位置进行对比；
- 同一问题至少重复测量；
- 测量结果接近允许边界时，由施工方或专业人员共同复核；
- 不同长度的靠尺、水平尺不能直接比较；
- 仪器显示精度不等于现场判断精度。

## 最值得购买的最小组合

普通业主先准备以下组合已经足够覆盖大部分现场检查：

1. 可靠卷尺；
2. 激光测距仪；
3. 小型激光水平仪；
4. 水平尺；
5. 空鼓锤；
6. 强光手电；
7. 可移除标签和记号笔；
8. 手机相机与云端备份。

专业仪器按项目需要借用或让专业人员提供，不必为了偶尔一次检查全部购买。
