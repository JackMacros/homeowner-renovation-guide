# 报价、合同、付款与质保

[返回专题总览](index.md)

## 报价的目标

一份可管理的报价，不只是告诉业主总价，而应回答：

> 在哪里，用什么材料，以什么单位计算，完成哪些工作，不包含什么，做到什么程度，怎样验收。

如果两个报价的范围、材料和计算规则不同，总价没有直接可比性。

## 每条报价应有的字段

- 房间或施工区域；
- 工序名称；
- 工作内容；
- 材料品牌、完整型号和规格；
- 人工、主材、辅材分别由谁承担；
- 工程量；
- 计量单位；
- 单价和合价；
- 损耗、运输、上楼和垃圾清运；
- 开孔、切割、收口和修补；
- 验收标准；
- 明确排除项。

“水电一项”“卫生间一项”“墙面处理一项”都过于笼统。

## 容易漏掉的费用

- 物业押金、出入证和垃圾处理；
- 成品保护及最终拆除；
- 垃圾装袋、搬运、下楼和外运；
- 材料上楼和二次搬运；
- 打孔、开槽、修补和洞口加固；
- 瓷砖切割、倒角、磨边和异形加工；
- 美缝、收边、门槛和地漏节点；
- 设备电源、排水、控制线和检修口；
- 安装辅件、角阀、软管、密封胶和紧固件；
- 复测、调试、保洁和成品修补；
- 退换货、补货运费及不足一整包装的采购。

## 合同附件比正文更重要的部分

建议把以下文件作为合同附件并编号：

1. 确认图纸；
2. 报价和工程量清单；
3. 材料清单；
4. 工艺及关键节点说明；
5. 进度和进场计划；
6. 阶段验收表；
7. 付款节点；
8. 变更单格式；
9. 成品保护和工种交接规则；
10. 质保范围和联系方式。

发生冲突时，应提前约定正文、图纸、清单和现场变更的解释顺序。

## 付款设计原则

付款不应只绑定日期或“工程过半”，而要绑定可验证结果：

- 人员和材料实际进场；
- 某阶段施工完成；
- 必要等待和测试完成；
- 阶段验收通过；
- 资料和照片已经提交；
- 问题整改复验完成。

建议遵循：

- 预付款只覆盖合理的启动成本；
- 隐蔽工程在验收前保留付款约束；
- 不把大部分价款提前支付；
- 最终保留足以推动整改和资料交付的尾款；
- 材料款、人工款和定制生产款根据各自风险分别安排。

不建议机械套用统一付款比例。工程规模、材料采购方、定制比例和交易对象不同，应重点保证“钱的释放速度不快于合格工程的形成速度”。

## 增项必须满足的条件

增项施工前应形成书面变更，至少包含：

- 原约定是什么；
- 为什么需要改变；
- 新增或减少的内容；
- 材料和工艺；
- 工程量、单价和总价；
- 对工期和其他工种的影响；
- 谁提出、谁确认；
- 是否修改图纸和结算。

真正紧急的止漏、安全处置可以先控制损失，但仍应尽快补齐照片、原因、处理和费用记录。

## 工程量核对

常见单位包括米、平方米、个、项和套。核对时需要明确：

- 按建筑面积、展开面积还是实际施工面积；
- 门窗洞口是否扣除；
- 不足一个单位如何计算；
- 损耗是否已经包含；
- 重复计算的工序是否存在；
- 变更减少项目是否同步扣减。

对隐蔽后难以测量的工程量，应在覆盖前共同测量、拍照和签认。

## 验收与付款的关系

阶段款建议采用以下放行逻辑：

> 提交完工通知 → 达到养护或测试条件 → 业主检查 → 出具问题清单 → 整改复验 → 确认阶段合格 → 支付对应款项

工人“已经干完”只代表可以申请验收，不代表自动产生付款条件。

## 质保需要写清楚什么

- 质保对象和范围；
- 起算时间；
- 不同问题的响应方式；
- 谁负责上门判断；
- 人工、材料和拆装损失如何承担；
- 施工问题与产品问题怎样衔接；
- 联系人变化后的替代联系方式；
- 不属于质保的情形。

不要只写“质保若干年”，却没有说明漏水后谁拆砖、谁恢复柜体和谁承担连带损失。

按照现行《住宅室内装饰装修管理办法》，正常使用条件下住宅装修最低保修期为2年；有防水要求的厨房、卫生间和外墙面防渗漏最低保修期为5年，均从竣工验收合格之日起计算。合同可以约定更长，但不宜低于法定最低线。详细来源见[一手来源研究笔记](../references/topic-source-notes.md#3-最低保修期限与交付资料)。

签约时可先查询[国家市场监督管理总局合同示范文本库](https://htsfwb.samr.gov.cn/)，优先采用房屋所在地最新住宅装修示范合同，再根据清包、半包或全包实际补充附件。

## 签约前检查清单

- 合同主体与收款主体一致或关系明确；
- 工程地址、联系人和施工负责人正确；
- 工作范围与排除项清楚；
- 材料不是只写品牌；
- 图纸、报价和附件版本一致；
- 开工、阶段工期和延期处理明确；
- 付款绑定验收结果；
- 增减项必须事前书面确认；
- 返工、成品损坏和第三方损失责任明确；
- 质保和争议处理方式明确。

涉及金额较大或责任复杂时，可使用当地主管部门、消费者组织等发布的示范文本，并考虑让专业人士审阅。
