## 使用原则

1. 专题中的方法用于管理项目，不代替专业设计和检测；
2. 品牌只能建立候选池，最终必须落实到完整型号和适用条件；
3. 合同和付款安排应结合当地示范文本及实际交易对象；
4. 涉及结构、燃气、供暖和带电检测的事项，应交给具备相应能力的人员；
5. 所有约定最终应进入合同、附件、图纸、订单或现场书面记录。
