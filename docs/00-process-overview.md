# 毛坯房装修整体施工流程

## 这份总览解决什么问题

本页用于把控整个装修项目。先在这里确认当前处于哪个阶段、前后工序是什么、是否具备进入下一阶段的条件，再进入具体工序页面查看材料、工艺、风险和验收细节。

装修不是“做完就进入下一步”，而应始终遵循下面的放行闭环：

> 检查进场条件 → 核对材料 → 确认工艺和价格范围 → 施工留证 → 等待或养护 → 停工验收 → 整改复验 → 成品保护 → 放行下一阶段

## 开工前必须具备的资料

正式进入施工阶段前，至少应具备：

- 经确认的平面布局和拆改范围；
- 家具、家电及主要设备尺寸；
- 开关插座、给排水、照明等点位；
- 空调、新风、地暖等设备方案；
- 主要材料和施工范围约定；
- 物业申报结果及施工限制；
- 报价、付款节点和变更规则。

没有这些资料时，不宜仅凭现场口头交流开始拆改。

## 顺序不是绝对直线

门窗、中央空调、新风、水电等可能交叉施工；定制柜、瓷砖、室内门也需要提前选型或复尺。判断能否穿插，不看“哪个工人有空”，而看三个条件：

1. 是否会遮盖尚未验收的内容；
2. 是否会破坏已经完成的成品；
3. 尺寸、材料和接口是否已经确认。

只要其中一项不确定，就不应为了赶进度强行进入下一工序。

## 五个最高优先级停检点

以下节点未验收，不应覆盖：

1. 水电管线封槽前；
2. 防水层被保护层或瓷砖覆盖前；
3. 吊顶封板前；
4. 地板、柜体等覆盖基层前；
5. 整改完成、尾款支付前。

## 等待时间的使用原则

施工中的等待不能只写成固定“几天”。每次等待都应同时记录：

- 从什么时间点开始计算；
- 等待是为了干燥、固化、养护还是测试；
- 环境温度、湿度是否影响时间；
- 产品技术说明规定的条件；
- 达到什么状态后可以验收；
- 验收合格后由谁放行。

例如防水阶段应区分层间等待、完工养护和闭水试验，不能笼统地合并成“防水后等两天”。

## 全项目统一记录

建议从开工第一天建立以下五份记录：

- **材料进场表**：品牌、完整型号、规格、批次、数量、购买渠道；
- **隐蔽工程照片**：全景、近景、尺寸和所在房间；
- **问题整改表**：位置、问题、责任人、期限、复验结果；
- **现场变更表**：原因、内容、费用、工期影响、确认人；
- **付款记录表**：对应工作范围、验收结果和未完成事项。

## 材料选择的统一原则

材料不能只看品牌。每一项至少核对：

> 品牌＋完整产品名称＋型号规格＋执行标准＋生产批次＋适用位置＋理论用量＋配套辅材＋购买渠道

同品牌不同系列可能具有完全不同的性能和价格；主材合格也不能弥补辅材不配套或施工条件不合格。
