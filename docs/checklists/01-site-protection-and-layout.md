# 01 现场保护与施工放线｜现场清单

[详细说明](../stages/01-site-protection-and-layout.md) · [返回清单总览](index.md)

## 开工前

- [ ] 物业申报、施工时间和清运要求明确
- [ ] 拆改图、平面图和关键设备尺寸为确认版本
- [ ] 原房裂缝、渗水、门窗和公共区域已经拍照
- [ ] 临时用水、用电和如厕方案明确
- [ ] 临时便器（如使用）由施工方按合适排污接口安装，防臭/冲洗和清理责任明确；不向雨水口或不明管道排污
- [ ] 图纸已确认版本、日期；旧版图纸已标注作废或收回
- [ ] 结构图、物业装修手册、拆改方案、设备型号/尺寸已准备
- [ ] 业主、施工负责人、物业共同巡查并给保留物分类：保留/临时拆装/允许拆除
- [ ] 原房裂缝、渗水、空鼓（如有）、门窗、表箱和公共区域均已拍照留存，照片能定位房间/位置

## 保护和封堵

- [ ] 入户门、窗框、电梯和公共通道保护完整
- [ ] 地漏、马桶排污口及其他管口可靠封堵
- [ ] 保护材料固定可靠且不会损伤原成品
- [ ] 保护板、护角、保护膜/胶带到货已核品名规格、数量和外观，受潮/破裂品已隔离
- [ ] 保护区域和材料用量按实际覆盖面、搬运路线、搭接/裁切和管口数量核算
- [ ] 物业有指定板材/阻燃要求时已取得要求并按要求验收，没有把普通塑料板误称为阻燃材料
- [ ] 保护层铺设前地面已清洁无砂粒，铺设后无明显滑移、翘边、露底或遮挡使用功能
- [ ] 保护材料采购、铺设、每日检查、拆除、清运及损坏责任已书面确认
- [ ] 采购单、送货单和包装标签已核对品名/规格/数量；破损、短缺已在单据备注并拍照
- [ ] 临时用电具备必要保护
- [ ] 电梯、厅门、楼道转角按物业要求保护并完成交接，未遮挡消防/疏散设施
- [ ] 入户门、门框、窗框玻璃、窗台保护牢固，门窗/锁具/排水孔仍可正常使用
- [ ] 水表、燃气表、分集水器、配电箱及检修口可读、可操作、未被封死
- [ ] 地漏、排污口、管口使用可拆卸堵头并挂牌；堵头数量已记录，无抹布/纸团/砂浆入管
- [ ] 保护膜/胶带在对应材质上已做小面积试贴，计划拆除时间和责任人已明确
- [ ] 地面保护层下无砂粒，搬运路线有抗冲击保护，保护层未翘边或堵住门扇

## 放线

- [ ] 拆除线、保留线和新建线能明确区分
- [ ] 门洞、柜体、洁具和大型设备位置已标出
- [ ] 关键尺寸从明确基准和装修完成面计算
- [ ] 长宽在房间两端和中部复测；有改墙/定制家具区域已记录两条对角线
- [ ] 测量记录含墙面方向、洞口离角尺寸、梁柱/管井/烟道凸出、地漏位置及测量日期/人员
- [ ] 激光水平仪按说明检查自整平/报警状态并复测基准；异常时已用其他工具复核
- [ ] 定制柜、门窗、淋浴隔断等需要厂家复尺的尺寸已标明二次复尺责任人和时间
- [ ] 门扇、柜门和家电开启范围无明显冲突
- [ ] 通道宽度和家具摆放已经现场模拟
- [ ] 现场实测长宽、层高、墙角、对角线、柱/梁/管井/窗台等已标回图纸
- [ ] 水平基准位置、标高含义、结构面与装修完成面区别已标注
- [ ] 每个尺寸有明确起止面（结构/抹灰/瓷砖/柜体完成面），墙不方正处有实测记录
- [ ] 新墙已画两侧边线并注明厚度、材料和定位尺寸
- [ ] 门洞宽高注明是砌筑洞口还是完成净洞口；门套厚度、门扇开启方向已核对
- [ ] 拆除线、保留线、新建墙、门洞、设备点位使用已约定的图例标记
- [ ] 冰箱、洗衣机、床、衣柜等按实际尺寸在地面模拟，柜门/抽屉/房门开启无冲突
- [ ] 地漏、洁具中心、检修口和管线位置已确认；未定型号的设备尺寸标记“待复核”
- [ ] 放线与图纸差异、变更原因、尺寸、价格/工期影响已记录并双方确认
- [ ] 业主/指定验收人和施工负责人在同一版图纸/照片上完成放线确认

## 放行

- [ ] 图纸与现场差异已有记录
- [ ] 结构性质不明确的位置已暂停并查明
- [ ] 清运、损坏和保护责任已书面确认
- [ ] 验收人明确同意开始拆除
- [ ] 合同约定的本阶段验收条件已满足；阶段款按书面条件支付，不以单纯到场或画线代替验收
- [ ] 施工负责人已说明图纸版本、现场图例和量尺起止面；现场改动已同步回写图纸
- [ ] 未定型号设备位置标注暂定值、复核责任人和截止点；结构/管线不明项未被误当作允许拆除
- [ ] 所有不明墙体、管线、物业限制均已查明；不明处已明确暂停，不先试拆
- [ ] 保护、封堵、物业交接和放线照片已归档到同一项目文件夹

结论：未通过 / 有条件通过 / 通过
