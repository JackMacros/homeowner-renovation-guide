# 04 门窗、空调、新风等前置工程｜现场清单

[详细说明](../stages/04-windows-and-hvac.md) · [返回清单总览](index.md)

## 开工前放行

- [ ] 03阶段墙位、窗洞和完成面尺寸已复核，门窗编号与房间对应
- [ ] 外窗更换、外机位、外墙开孔和施工时段已向物业核实；需审批的已有书面手续
- [ ] 每台设备完整型号、安装尺寸和厂家安装资料已拿到
- [ ] 空调室内/外机、新风主机、风口、检修口和冷凝水点位已落图
- [ ] 05水电与09吊顶工人已确认电源、控制线、排水、吊顶高度和检修接口
- [ ] 分体机/多联机系统图、冷媒管规格表、新风风量/管路图已确认（适用时）
- [ ] 报价区分主机、辅材、打孔、安装、测试、调试、清运和售后；超量收费有书面算法

## 到货验收

- [ ] 空调内外机铭牌型号、序列号、数量与订单/送货单一致
- [ ] 新风主机、滤网、控制器及随机附件数量齐全，外箱和机身无明显破损
- [ ] 铜管、保温管、冷凝水管、风管及配件标签/规格与确认清单匹配
- [ ] 每樘窗的窗号、尺寸、开启方向、型材、玻璃构成、五金和纱窗与加工单一致
- [ ] 窗框、玻璃、密封条无明显变形、裂纹、崩边或受潮损伤
- [ ] 实际门窗加工厂、玻璃生产企业和安装方已分别记录；认证/报告对应实际产品
- [ ] 数量短缺、错型号、混配或运输损坏已拍照并写入送货单，争议件已隔离

## 外窗隐蔽检查

- [ ] 拆旧后洞口无未处理的结构破损、钢筋暴露或持续渗水疑点
- [ ] 框体定位、垂直/水平校正和机械固定完成，覆盖前已拍四边固定点
- [ ] 框墙填缝、内侧气密、外侧防水密封按确认节点分别完成
- [ ] 密封胶与基层/窗框相容，排水孔未被泡沫、密封胶或砂浆堵住
- [ ] 窗扇开关、锁闭、限位和排水测试完成
- [ ] 密封材料达到产品规定固化条件后，已按合同方法分区淋水并记录

## 空调/新风隐蔽检查

- [ ] 冷媒管规格、走向、长度/高差记录与设备安装表相符
- [ ] 铜管弯曲无明显压扁/折瘪，端口施工期间有封堵
- [ ] 保温连续，弯头、接头、阀件等位置没有裸露或破损
- [ ] 冷凝水管有可靠支撑、路径无明显下垂/倒坡，排点位置已确认
- [ ] 冷凝水已从设备端持续通水至最终排点，沿线及吊顶内接口无渗漏
- [ ] 风管、风阀、消声段、风口与系统图一致，无明显压扁、随意缩径或漏装
- [ ] 设备吊架锚固可靠，减振件齐全，管线不与吊顶龙骨/灯具冲突
- [ ] 滤网、阀件、接头、冷凝水盘及电气盒可按实际动作检修
- [ ] 保压/检漏、抽真空、冷媒追加和调试记录已按厂家参数填写（适用时）
- [ ] 新风每个测点的风量/系统平衡记录已交付（适用时）
- [ ] 隐蔽管线全景、近景和带尺定位照片已归档，图纸已标实际路径

## 整改与放行

- [ ] 窗户渗水、开启异常、玻璃/框体损伤均有整改与复验记录
- [ ] 空调结露、漏水、异响、振动、制冷/制热异常已复核处理
- [ ] 新风方向、风量、滤网抽取和检修口可用性已检查
- [ ] 05水电与09吊顶已接收接口图、检修要求和隐蔽照片
- [ ] 设备序列号、订单发票、安装调试单、保修资料和售后联系人已归档
- [ ] 所有隐蔽问题复验通过后才签字封板/支付对应节点款

结论：未通过 / 有条件通过 / 通过
