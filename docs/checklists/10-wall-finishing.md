# 10 墙面基层与涂装｜现场清单

[详细说明](../stages/10-wall-finishing.md) · [返回清单总览](index.md)

## 基层与开工条件

- [ ] 逐房逐墙编号，记录基层材质、空鼓/起砂/裂缝/潮斑/旧墙及修补位置
- [ ] 外窗、管线、邻户等渗漏/返潮原因已排除；霉斑处已查源而非只刷防霉漆
- [ ] 空鼓、粉化、松动层已清至坚实基层；活动/结构裂缝未被腻子遮盖
- [ ] 09吊顶板缝、墙顶交界和门窗/瓷砖/柜体收口方案已交接
- [ ] 门窗、瓷砖、插座盒、地面和设备已保护
- [ ] 普通或高级涂饰等级、颜色/光泽/质感、分色线和样板已书面确认

## 材料到货

- [ ] 订单、送货单、包装、合格资料、检测报告及发票型号和生产者一致
- [ ] 实际生产企业/地址、产品名/型号、执行标准年份、批号/日期、保质期、净含量和数量已记录
- [ ] 室内腻子按`JG/T 298-2010`核对Y/R/N类别、适用部位和批次；未把`GB/T 23455-2009`外墙腻子误当室内标准
- [ ] 水性内墙涂料属于CCC目录定义范围时，证书状态、型号/认证单元、制造商和生产厂已核验
- [ ] 未把腻子、外墙涂料、建筑无机粉体涂料等一概要求CCC，也未拿同品牌其他型号证书代替
- [ ] 有害物质资料按`GB 30981.1-2025`核版本、报告日期、样品型号和生产者；旧版资料差异已解释
- [ ] 底漆、面漆、界面剂及修补料明确完整型号、配套关系、颜色代码、稀释和重涂要求
- [ ] 色漆同色号/同批次备料；受潮结块、过期、封口破损、异常分层或标签缺失材料已隔离

## 基层测量与施工过程

- [ ] 已按基层和涂装体系确定含水率测法；混凝土/抹灰基层溶剂型≤8%、乳液型≤10%，木基层≤12%（按GB 50210-2018第12.1.5及适用产品要求核对）
- [ ] 每房间含水率测点、仪器、基层类型和读数已记录；高湿/修补/潮斑部位加测
- [ ] 界面剂只在体系/基层需要时按说明使用；未用底涂遮粉化、油污或空鼓
- [ ] 稳定裂缝、开槽、新旧墙、板缝和异材交界按确认方案修补/增强；覆盖前已拍照
- [ ] 找平料、腻子配比和可使用时间按说明；未单遍厚批、过量加水或续用超时料
- [ ] 每遍找平/腻子/底漆/面漆施工日期、环境条件（产品要求时）、用量和等待依据有记录
- [ ] 腻子达到干燥条件后打磨，浮灰清除；侧光及靠尺抽查无未修复高低点
- [ ] 底漆和面漆未擅自省略、过量兑水或跨系列混搭
- [ ] 样板墙使用最终基层、底漆、色号、面漆和工具，在约定光线下已确认

## 停检与验收

- [ ] 基层封闭前：渗漏、潮湿、霉变、空鼓、粉化、裂缝均已查因/闭环
- [ ] 裂缝/板缝/新旧墙处理覆盖前：节点材料、范围、照片记录已确认
- [ ] 腻子打磨后、底漆前：牢固、含水、平整度、阴阳角和浮灰已检查
- [ ] 大面积面漆前：样板颜色、光泽、纹理、施工工具和涂饰等级已签字确认
- [ ] 完工后自然光、主灯和设计洗墙灯下检查颜色、光泽、漏涂、透底、开裂、起皮、掉粉、流坠、砂眼/刷纹
- [ ] 2m靠尺/塞尺抽检位置及读数有记录；阴阳角、柜体/门套/踢脚线接口已重点检查
- [ ] 分色线、涂层与门窗/瓷砖/设备交界吻合、界面清晰
- [ ] 轻擦试验在产品养护完成后按说明进行，未用强溶剂/尖锐工具破坏涂层
- [ ] 异常已按基层原因修复并在养护后复验；单纯补漆色差明显时已整面处理

## 保护与放行

- [ ] 墙面达到产品养护条件，已防碰撞、早期擦洗、胶带粘贴和污染
- [ ] 涂料型号、色号、批次、样板、材料报告/CCC记录、用料和整改记录已归档
- [ ] 后续打孔区域已对照水电隐蔽图；门柜/灯具安装后的补漆责任已明确
- [ ] 室内空气正式检测标准和采样条件留到13章确认，未以气味/“净味”判定可入住
- [ ] 业主/指定联系人书面放行后进入11章安装，未关闭问题已关联整改期限和付款条件

结论：未通过 / 有条件通过 / 通过
