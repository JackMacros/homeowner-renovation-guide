# 11 门、柜体、台面与地板｜现场清单

[详细说明](../stages/11-doors-cabinets-and-flooring.md) · [返回清单总览](index.md)

## 下单与复尺

- [ ] 门洞按完成面复尺，逐樘记录洞宽/高/墙厚、开向、门套和门底缝用途
- [ ] 柜体深化图标出板种/厚度/封边、五金型号、见光面、插座阀门与检修空间
- [ ] 柜体图已与水电隐蔽图、设备型号及开门/散热/维修尺寸核对
- [ ] 台面加工前以实际水槽/灶具模板复核开孔、边型、拼缝和支撑并签图
- [ ] 地板品类、铺装系统、地暖适配、踢脚/压条和门口高度已书面确认
- [ ] 运输上楼、拆包、辅料、开孔、安装、垃圾、返场和损伤责任列入订单

## 到货验收

- [ ] 门、柜板、台面、地板的准确型号/规格/颜色/批次与订单、送货单和封样相符
- [ ] 记录每项实际生产者及生产地址；未把经销商/品牌运营地址当生产厂址
- [ ] 木质板件的板种、厚度、饰面、封边和检测资料对应到实际产品/生产厂
- [ ] 甲醛资料核对GB 18580-2025适用性；E1/E0/ENF级别另核GB/T 39600及报告方法/样品
- [ ] 五金逐项核品牌完整型号、规格、数量和配套件
- [ ] 台面材料类别、加工图、孔位、色差封样和运输外观已核
- [ ] 地板标签含产品类别、规格、批次、生产者、执行标准及地暖适用信息
- [ ] 受潮、破损、混批、错型号、短缺已隔离并在送货单备注、拍照留证
- [ ] 收货签字仅记录收货数量/可见外观，未提前确认未安装的功能质量

## 施工停检点

- [ ] 打孔/吊挂前核对水电、防水和墙体资料；固定基层及锚固方案已确认
- [ ] 柜体首件位置、水平垂直、门缝、检修口、阀门和设备开启范围已确认
- [ ] 吊柜/高柜连接由安装人确认，连接点及隐蔽位置留照
- [ ] 地板铺前记录基层类型、平整/强度/清洁和含水检测仪器、测点、读数
- [ ] 地暖状态、地板系统、地垫/胶/防潮层及复热条件与厂家要求一致
- [ ] 踢脚线/压条封边前已拍墙边伸缩空间、防潮层和门口节点
- [ ] 台面开孔前，设备模板、柜体复尺和加工图三方核对并签字
- [ ] 密封胶达到产品固化条件后再通水、擦洗或加载

## 完工验收与放行

- [ ] 每樘门开合、锁闭、合页、门吸正常，无刮地/碰撞/异常自行回摆
- [ ] 柜门、抽屉、拉篮及五金逐项全开全关，检修/散热路径可用
- [ ] 台面无未处理裂纹/崩边，拼缝/支撑符合签字图
- [ ] 水槽及下水接口待密封固化后试水，柜内无水迹
- [ ] 地板走查无未处理松动、弹跳、锁扣张开和明显异响
- [ ] 地板墙边、门口、分隔和固定柜体处按铺装系统留设伸缩/收口
- [ ] 划伤、破损、色差、尺寸和功能问题均有整改及复验记录
- [ ] 门表、深化图、板材/五金资料、地板标签、质保和余料信息已移交
- [ ] 成品保护完成，业主/指定联系人书面放行后进入12章

结论：未通过 / 有条件通过 / 通过
