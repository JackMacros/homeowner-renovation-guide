# 02 拆除与清运｜现场清单

[详细说明](../stages/02-demolition.md) · [返回清单总览](index.md)

## 开工放行

- [ ] 01阶段确认版拆改图已签认，现场每个拆除点有编号和清晰边界
- [ ] 墙体/构件性质已依据建筑、结构资料及必要的专业意见核实；不是只凭敲击声或墙厚判断
- [ ] 物业告知/登记、装修服务协议、施工时间、电梯/路线和垃圾暂存要求已确认
- [ ] 主体/承重结构、连接阳台墙、外墙、烟道、公共管线、燃气/供暖设施未被当作普通拆除项目
- [ ] 受影响的电、水、燃气、供暖、弱电等已明确由谁联系对应专业人员辨识和隔离；普通拆除工人不擅自拆改
- [ ] 拆前原状、既有裂缝/损伤、保留面、管口及搬运路线已拍照
- [ ] 拆除、装袋、户内搬运、下楼、车辆、处置/物业费用和超量计价已写清
- [ ] 当地装修垃圾分类、预约/联单责任人、承运方式、处置去向和交接凭据已确认

## 施工过程检查

- [ ] 当日作业范围与确认版图纸一致，未擅自扩大
- [ ] 第一处构造暴露后已停机检查；现场与图纸相符后才扩大作业面
- [ ] 靠保留边界、门洞、梁柱边、管井/烟道附近按交底受控施工
- [ ] 管口堵头有标识、固定且可拆；没有垃圾、灰浆进入地漏/管道
- [ ] 防尘、公共区域保护、消防通道和个人防护持续有效
- [ ] 垃圾及时分类装袋/装箱；没有在楼板局部、楼梯间或消防通道集中堆放
- [ ] 搬运路线每次清理；公共区域没有散落碎渣，临时堆放符合物业指定位置/时段
- [ ] 新增拆除量、损伤修复或额外费用均先书面确认再施工

## 立即停工信号

- [ ] 发现钢筋、混凝土结构构件、疑似梁柱/连梁、结构连接或不明厚实构造
- [ ] 发现不明电线、给排水/燃气/供暖/冷媒管，或发生漏水、异味、短路等异常
- [ ] 出现新裂缝、异常振动/声响、门窗变形或保留侧大面积松动
- [ ] 图纸与现场不一致、保护失效、消防通道被占或异常材料身份不明

上述任一项出现：停止相应区域作业，人员撤至安全位置，拍全景与近景并通知你、带班工人（如有）、物业及相关专业人员；没有专业核查和明确复工条件，不继续拆、不覆盖。

## 拆后验收与放行

- [ ] 拆除边界、墙垛/门垛和实际拆除量逐项对照图纸，无未经确认的扩大
- [ ] 梁、柱、楼板、保留墙体、门窗、烟道、立管和可见管线已检查；疑点有专业意见
- [ ] 保留边缘无未处理松动块、尖锐危险残留或被垃圾遮挡的异常点
- [ ] 地漏/管口堵头逐一核销；疑似进灰/堵塞处由专业人员清理并确认
- [ ] 门洞、墙位、通道和后续设备接口已用卷尺复测，尺寸写回当前版图纸
- [ ] 室内、暂存点、电梯/楼道和搬运路线垃圾已清理；交接、预约或费用凭据已保存
- [ ] 超范围、损伤、管线问题、整改和复验均有编号、照片、责任人和结论
- [ ] 拆前/过程/拆后照片、物业记录、垃圾交接凭据和更新图纸已归档
- [ ] 业主/指定验收人已书面放行03阶段；未闭环问题没有被砌筑或修补覆盖

结论：未通过 / 有条件通过 / 通过
