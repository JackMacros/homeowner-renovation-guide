# 09 吊顶、木工与隐蔽设备封板｜现场清单

[详细说明](../stages/09-ceiling-and-carpentry.md) · [返回清单总览](index.md)

## 开工条件与排布

- [ ] 04空调/新风与05水电隐蔽资料、测试结果已交到吊顶工人
- [ ] 08湿作业达到交叉施工条件，地面瓷砖/门口已保护
- [ ] 各室吊顶标高、最低净高、风口/灯具/窗帘盒/检修口位置已复尺并确认
- [ ] 已核对梁板结构图和隐蔽管线；钻孔位置、锚固基层和吊点经确认
- [ ] 设备检修口用纸板/实物模拟开盖、伸手、拆件，手和工具均可到位
- [ ] 吊灯、风扇、投影、幕布等已记录重量/振动和独立承重方案

## 材料到货

- [ ] 订单、送货单、包装标签、生产者/工厂、型号、规格、批次及数量一致
- [ ] 纸面石膏板核对`GB/T 9775-2025`版本、品种、尺寸、厚度、边型、日期/批次；破损/受潮板已隔离
- [ ] 龙骨主/副/边系列、截面、名义厚度、长度、镀层类别和配套连接件与报价一致
- [ ] 龙骨无明显锈蚀、扭曲、压瘪；抽测记录有位置、量具读数和照片，异常已暂停核查
- [ ] 螺钉、吊件、锚固件型号与系统及基层匹配，不混用不同体系零件
- [ ] 嵌缝料、接缝带、护角的用途/批次/保质期及配套关系已核对
- [ ] 木基层产品类型、厚度、生产者、批次及甲醛释放资料已留存；防火/防潮处理产品和施工范围明确
- [ ] 填充物类别、性能文件、燃烧性能、数量和干燥包装已核对；不会堵风口或检修路径

## 骨架和独立承重

- [ ] 吊杆、埋件/锚固、主副龙骨、边龙骨和连接件与确认图及系统说明一致
- [ ] 吊杆长度大于1.50m时已按`GB 55031-2022`第6.4.3条设置反支撑并确认连接
- [ ] 吊顶骨架未借挂在水管、风管、桥架或其他设备管线上
- [ ] 重量大于3kg或有振动荷载的设备未吊挂在龙骨/面板上，已按第6.4.2条直接连接建筑承重结构
- [ ] 设备支架不压管、不破坏保温；结构或锚固不明时已停止施工并取得专业确认
- [ ] 灯具、风口、检修口开孔未切断龙骨；需要边框/加固的位置已在封板前完成
- [ ] 窗帘盒、灯槽、局部木基层的用途、固定位置和后续可挂载范围已标记

## 封板前停检：设备、填充与证据

- [ ] 水管试压/通水、空调冷媒系统、冷凝水排水、风管/新风、电气等由各自安装者完成适用测试并交记录
- [ ] 冷凝水管/吊顶内水管保温连续，接缝、弯头和阀件无明显裸露/破损/结露迹象
- [ ] 潮湿房间顶棚材料及构造适用，已考虑防结露、防滴水和冷凝水排放
- [ ] 阀门、过滤网、风阀、接头、接线盒、泵等逐一能通过检修口实际操作/拆换
- [ ] 填充物连续且干燥，不压扁、不堵风口/散热/检修，不外露纤维
- [ ] 吊顶内部已清理，管口/风管端口按需要封护，未遗留垃圾和松散物
- [ ] 已拍每室全景、吊点与加固带尺照、管线走向、阀件/检修口、材料标签和测试记录
- [ ] 问题已整改复测；业主/指定联系人书面放行后才封板

## 封板与板缝

- [ ] 排板图已确认；板缝有支撑，板块无不必要窄条/四角汇缝，双层板按系统错缝
- [ ] 板材无受潮、破损、明显翘曲；开孔位置避开龙骨/线路且边缘有适用支撑
- [ ] 螺钉垂直、固定均匀；钉头无外凸，纸面未被大面积打穿/撕裂
- [ ] 接缝、阴阳角、窗帘盒/灯槽和异材交接使用相配嵌缝料/接缝带并按说明分层施工
- [ ] 首个房间/复杂造型样板已验收，再批量封板
- [ ] 嵌缝材料达到产品规定的干燥/覆涂条件，无开裂、起鼓或脱层

## 完成面与放行

- [ ] 激光/卷尺复核各室净高、关键最低点和标高，实测值与确认图/合同一致
- [ ] 靠尺/塞尺按约定位置检查平整，读数和位置有记录
- [ ] 侧光检查波浪、错台、钉眼、接缝、污染及开孔收边；不以腻子遮盖结构/固定缺陷
- [ ] 检修口开闭顺畅，能够维护目标设备，未被灯具、柜体或造型遮挡
- [ ] 吊顶内部照片/管线定位图、设备测试记录、材料标签和整改复验单已归档
- [ ] 10章墙面基层施工所需板缝/转角处理已交接；后续打孔禁区和加固位置已标注
- [ ] 未关闭的问题已列明责任人、整改期限与付款保留条件

结论：未通过 / 有条件通过 / 通过
