# 03 砌墙、门洞与基层修补｜现场清单

[详细说明](../stages/03-masonry-and-repair.md) · [返回清单总览](index.md)

## 开工放行

- [ ] 02阶段拆后复尺完成，使用同一版墙体/门洞图纸
- [ ] 墙体系统、规格、强度/密度等级（适用时）、厚度及两面完成面尺寸已写清
- [ ] 墙位、门洞、柜体、洁具、设备和开关管线位置已协调
- [ ] 重物固定位置、预计荷载和加固方法已确认
- [ ] 涉及楼板荷载、结构边或既有洞口的疑点已由专业人员核实
- [ ] 多人施工时已约定一位带班工人对接；单人施工时明确直接联系人

## 材料到货

- [ ] 包装标签、送货单、订单中的产品名、规格、等级、批次一致
- [ ] 生产企业和实际生产地址可追溯，不把经销商/仓库地址当工厂地址
- [ ] 生产日期、批号、数量和随货合格资料已核对并拍照
- [ ] 砌块/板材无明显裂损、严重崩角、受潮或批间差异；异常批次已隔离
- [ ] 砌筑砂浆与墙体系统匹配，生产日期、保质期、包装完整
- [ ] 拉结件、网布、过梁/门洞件、重物加固件与确认图纸/系统节点匹配

## 隐蔽施工检查

- [ ] 第一段样板确认了墙线、灰缝/板缝、垂直平整和材料使用方法
- [ ] 墙脚和基层坚实、干净，湿区节点没有套用未经确认的统一做法
- [ ] 新旧墙/主体连接按设计或系统完成，覆盖前拍带尺照片
- [ ] 砌块错缝，未用大量碎块拼砌；砂浆按产品说明配料、使用
- [ ] 门洞过梁/洞边加强按设计或系统完成；未用木板/随手钢件代替
- [ ] 吊柜、电视、热水器等加固件已完成并标注范围/高度
- [ ] 墙顶连接按对应墙体系统施工；填充墙连接空隙按要求等待14天后处理
- [ ] 抗裂网材质、搭接和埋置方式符合设计/系统；没有遮盖空鼓或未填实槽口
- [ ] 拉结、过梁、加固及将被抹灰覆盖部位已检查留证

## 完工验收与放行

- [ ] 墙位、长度、厚度和高度对照图纸复核，完成面净尺寸满足设备/通道要求
- [ ] 适用砌体填充墙时，对照GB 50203-2011表9.3.1检查偏差
- [ ] 门洞上/中/下宽、左右高度、对角线和墙厚已记录并交门厂复尺
- [ ] 若有一般抹灰，对照约定的普通/高级抹灰等级及GB 50210-2018表4.2.10检查
- [ ] 墙体无未处理松动、贯穿/发展裂缝、明显脱层或空鼓
- [ ] 结构、门洞、管线和加固疑点已由对应专业人员处理/确认
- [ ] 实际墙位、洞口、加固区和禁止开槽/打孔区域已更新并交给后续工人
- [ ] 整改复验、材料凭证和隐蔽照片已归档；未解决问题没有被覆盖

结论：未通过 / 有条件通过 / 通过
