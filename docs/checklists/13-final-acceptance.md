# 13 整体验收、整改与交付｜现场清单

[详细说明](../stages/13-final-acceptance.md) · [返回清单总览](index.md) · [打开完整交付模板](../templates/08-final-handover.md)

## 验收前准备

- [ ] 合同/报价、全部变更、订单、付款凭证和前12章验收记录已备齐
- [ ] 供货人、安装工人、电工、燃气服务等实际责任接口已列清
- [ ] 水、电、网络和设备具备测试条件；专业测试人员/服务已预约
- [ ] 保留保护膜至检查完成；准备房间图、问题表、相机、手电、卷尺和纸巾
- [ ] 未完成、仍养护、不能测试的项目已提前列明，不按“口头完成”处理

## 安全优先筛查

- [ ] 无持续漏水、燃气异味、焦糊气味、裸露电线或异常跳闸/发热
- [ ] 吊柜、灯具、热水器等固定无松脱迹象；检修口和阀门可操作
- [ ] 发现安全/持续损害风险时已停用/隔离并联系对应专业人员

## 按房间检查

- [ ] 入户/玄关：门锁、门窗、地面、收口、开关和设备
- [ ] 客餐厅：墙顶地、灯具、插座、网络、柜体和空调/新风
- [ ] 厨房：柜体/台面、烟机/灶具、龙头水槽、洗碗机、进排水
- [ ] 卧室：门窗、墙顶地、灯光、插座、柜体及设备
- [ ] 卫生间：洁具、龙头花洒、地漏排水、电气保护和密封
- [ ] 阳台/设备区：门窗、洗衣/净水设备、排水、检修与防水交接
- [ ] 外观检查在自然光和正常使用照明下完成，问题有房间/墙向定位

## 按系统与专业测试

- [ ] 给水各点通水，柜内/设备接口用干纸巾检查无水迹
- [ ] 台盆/水槽蓄水排放、坐便器多次冲水、淋浴/地漏持续排水正常
- [ ] 电工完成适用的接地、极性、剩余电流保护等测试并留记录
- [ ] 开关控制关系、灯具功能、配电箱回路标签与实际一致
- [ ] 燃气设备有专业安装/检漏/调试记录，无装修工擅自改管
- [ ] 空调/新风/地暖、洗衣机/洗碗机等完成约定运行和排水测试
- [ ] 网络端口、智能设备本地控制、断网/断电恢复及管理员权限已确认
- [ ] 全屋设备联合运行时未出现异常跳闸、漏水、报警或设备冲突

## 问题单、整改和复验

- [ ] 每项问题有编号、准确位置、现象照片、验收依据/约定效果
- [ ] 供货/运输/安装/专业服务等责任接口和整改责任人已记录
- [ ] 整改内容、完成期限、成品保护和复验方法已书面约定
- [ ] 安全、漏水、核心功能问题优先处理，整改前停止使用/覆盖
- [ ] 每项整改按原检查方法复验，填写日期、结果和复验照片
- [ ] 未完成事项及相应付款安排经双方书面确认；不口头销项

## 资料、结算和正式交付

- [ ] 最终图纸、回路/阀门位置、隐蔽照片和测试记录已归档
- [ ] 材料清单、型号/批次、发票、CCC资料（适用时）已移交
- [ ] 产品说明、安装调试单、序列号、保修凭证和联系人齐全
- [ ] 钥匙、门禁、智能账户/重置方法、备用件和余料已交接
- [ ] 变更、增减项、已付款、未完事项和最终结算逐项核清
- [ ] 空气检测（如做）已书面确认适用标准、采样条件、机构和项目
- [ ] 双方签署/确认的交接记录与现场实际一致；尾款按合同/书面约定处理

结论：不具备交付 / 有遗留事项、按书面协议交付 / 正式交付
