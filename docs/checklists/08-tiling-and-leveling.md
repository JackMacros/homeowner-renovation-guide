# 08 瓷砖铺贴与地面找平｜现场清单

[详细说明](../stages/08-tiling-and-leveling.md) · [返回清单总览](index.md)

## 开工前

- [ ] 防水及闭水已经验收放行
- [ ] 瓷砖规格、色号、批次和等级已核对
- [ ] 粘结材料与砖材、规格和基层匹配
- [ ] 排版、缝宽、起铺点和窄条处理已确认
- [ ] 地漏、门槛、门、柜体和地板高度已协调
- [ ] 表面样砖已在自然光、室内灯光、侧光下看过；湿擦/污渍清洁测试已做
- [ ] 柔光/亮光的观感选择与防滑性能分别确认，没有把“柔光”当“防滑”
- [ ] 卫生间地砖已核对具体型号的防滑检测资料，规格和坡面排版已确认
- [ ] 报价按元/㎡同口径比较，搬运、切割、倒角、开孔、胶/砂浆、填缝、损耗、退补货分别列项
- [ ] 三家报价对比的是同规格、同等级、同表面、同送货/加工条件
- [ ] 品牌、系列、完整型号、规格、厚度、色号、批次、等级、产品报告和退补货规则已写入订单
- [ ] 到货时订单、送货单、包装标签三方已逐项核对，标签照片覆盖各型号/色号/批次
- [ ] 同一连续空间的色号、尺码和批号已核对；混批材料已隔离，未擅自混铺
- [ ] 已记录生产者全称及实际生产地址，未把经销商地址/营销中心当制造地址
- [ ] 已核对吸水率类别/执行标准；E≤0.5%只按产品资料判定，不用滴水代替检测
- [ ] 已核验包装所称“优等品”/5A等等级的具体依据；GB/T 4100产品符合性与质量分级分别核对，宣传对应具体型号、报告/证书
- [ ] 适用范围内的瓷质砖已核查CCC证书状态、生产企业和证书覆盖型号；CCC不替代本批外观、尺寸验收
- [ ] 放射性资料核对的是GB 6566-2010 A类指标/有效资料，不笼统把“A类”当成万能认证
- [ ] 已清点箱数/片数/面积，抽查托盘上中下层；破损、短缺和未开箱情况记入送货单
- [ ] 同型号抽样检查颜色、纹理、边角、釉面、尺寸和翘曲，并留存外箱标签、照片及封样砖
- [ ] 瓷砖胶、背胶/界面材料、十字卡、调平底座、楔片/旋钮、填缝材料已分列型号和数量
- [ ] 调平卡扣按排版图和具体产品用量表核量；一次性底座与可重复用楔片/旋钮分开盘点
- [ ] 工人已演示卡扣安装、适度施力及沿砖缝方向拆除；已确认卡扣不会替代基层找平和胶浆覆盖
- [ ] 辅料型号、适配砖材/基层、有效期、说明书、用量和余料归属已确认
- [ ] “滴水测试”仅用于同批样砖的粗略比较；正式吸水率类别以产品报告和现行检测方法为准
- [ ] 主要区域排版图确认，门口/墙角/窗边窄条和地漏拼缝已提前看过
- [ ] 瓷砖胶/粘结材料的完整型号、说明书及适用规格已确认；未接受“万能胶/都能贴”的口头说法

## 施工过程

- [ ] 首个样板区域已确认后再大面积铺贴
- [ ] 基层牢固、干净且满足铺贴体系要求
- [ ] 粘结材料按要求使用，无超时和随意加水
- [ ] 胶浆覆盖充分，砖角、砖边无明显缺料
- [ ] 砖缝顺直、宽度基本一致
- [ ] 阳角、开孔、管根和不同材料交接整洁
- [ ] 地漏处形成明确坡向且地漏为低点
- [ ] 防水层未被打孔或施工破坏
- [ ] 胶浆按说明书配制，没有二次随意加水或使用结皮/超时胶浆
- [ ] 没有四角点粘、边框粘或用瓷砖胶堆厚度找平
- [ ] 首片、首排及样板区已复核水平、垂直、缝宽、收边后再铺大面
- [ ] 施工中抽起砖检查胶浆转移/覆盖，问题已即时调整并留照片
- [ ] 卫生间地漏和门槛的坡向、完成面高度按确认方案施工
- [ ] 瓷砖胶和所谓“背胶”是否配套有产品说明/书面依据，未任意混搭

## 等待与验收

- [ ] 达到材料规定的上人和检查条件
- [ ] 在适当养护后逐面轻敲检查空鼓
- [ ] 空鼓位置已编号、拍照并按位置风险判断整改
- [ ] 靠尺、水平尺检查关键墙地面
- [ ] 自然光和正常灯光下无明显色差、崩边和污染
- [ ] 涉水区域泼水或连续放水，无明显倒坡和积水
- [ ] 厕浴间瓷砖饰面完成并达到材料允许蓄水条件后，已按GB 55030-2022第6.0.12条完成第二次蓄水试验并检查楼下/相邻区域
- [ ] 允许上人、填缝、空鼓检查的时间按实际产品说明书确定并留存，不凭固定天数猜测
- [ ] 侧光下检查波浪、划伤、崩边、污染；自然光和夜间灯光下检查色差
- [ ] 用靠尺/塞尺检查重点区域，用空鼓锤轻敲并标记、拍照，不猛烈敲击
- [ ] 开孔、阳角、切割边、门槛及柜体/门套交接已逐处验收

## 放行

- [ ] 整改补贴后重新养护和复验
- [ ] 完成面高度已提供后续工种
- [ ] 成品保护完整
- [ ] 同批次维修余砖已保留
- [ ] 验收结果、空鼓点位、排水测试、整改和复验均留有照片/记录

结论：未通过 / 有条件通过 / 通过
