# 12 开关、灯具、洁具与设备｜现场清单

[详细说明](../stages/12-fixtures-and-equipment.md) · [返回清单总览](index.md)

## 到货与安装准备

- [ ] 每件设备已核完整型号、规格参数、制造商/生产厂、批次/序列号和附件
- [ ] CCC目录适用性已按品类核实，证书覆盖实际型号/生产厂（适用时）
- [ ] 设备模板、完成面、柜体尺寸与插座/阀门/排水/排烟接口相符
- [ ] 隐蔽图、防水记录、吊顶加固和检修位置在打孔/固定前已复核
- [ ] 安装方、专业责任方、辅料/耗材及费用边界已书面确认
- [ ] 燃气器具由燃气/品牌专业服务人员安装，气种和排气条件已确认

## 开关插座与灯具

- [ ] 开关控制对象/双控/智能场景与房间点位表一致
- [ ] 插座型号、额定参数、插头空间和使用位置符合设计及设备要求
- [ ] 电工按适用项目测试插座极性、PE接地和剩余电流保护并留记录
- [ ] 配电箱回路标签与实际控制范围核对，未发现异常跳闸/发热/异味
- [ ] 灯具、驱动、调光/智能模块型号和兼容性一致
- [ ] 吊灯、浴霸和风机固定到确认的承载基层；驱动/检修件可维护
- [ ] 灯具无明显闪烁、异响、异常重启或同区域明显色差

## 洁具、热水和厨房/洗衣设备

- [ ] 坐便器排污方式/坑距按准确型号图与完成墙面实测匹配
- [ ] 龙头冷热方向、螺纹接口、软管和密封垫与预留兼容
- [ ] 台盆/水槽蓄水排放后，柜内纸巾和接头检查无水迹
- [ ] 坐便器多次冲水后底座、进水和排污接口无渗漏/返味异常
- [ ] 花洒各模式及冷热切换正常，排水通畅
- [ ] 电热水器注满水并排气、确认无漏水后才通电
- [ ] 燃气器具已取得专业安装/检漏/调试记录，未由装修工自行改接
- [ ] 烟机排烟连接、止回和检修可达；未擅改公共烟道
- [ ] 洗碗机/洗衣机/净水器完成厂家要求的首次运行及进排水检查
- [ ] 阀门、插头、滤芯、设备检修和散热空间可操作

## 停检、测试与放行

- [ ] 接口被盖板/柜体遮住前已拍照并完成可见检查
- [ ] 密封材料达到产品说明的固化条件后再通水/擦洗/加载
- [ ] 单件设备逐一测试，整屋常用设备组合联合运行完成
- [ ] 漏水、电气异常、噪声、报警和功能问题已整改并按原项目复测
- [ ] 安装调试单、铭牌/序列号、说明书、质保和测试记录已归档
- [ ] 业主/指定联系人书面放行后再进入13章整体验收

结论：未通过 / 有条件通过 / 通过
