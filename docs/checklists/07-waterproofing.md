# 07 防水与闭水试验｜现场清单

[详细说明](../stages/07-waterproofing.md) · [返回清单总览](index.md)

## 开工条件与范围

- [ ] 06基层验收通过；空鼓、起砂、裂缝和倒坡已处理
- [ ] 05管线及地漏位置已锁定；防水施工期间不再开槽/移管
- [ ] 防水区域图标出地面、淋浴墙、盥洗处、其他泛水及门口收头
- [ ] 地漏、门口和相邻房间完成面标高已复核；门口有防止水外溢方案
- [ ] 施工人已确认产品的基层干湿、底涂、环境和养护要求

## 主材到货

- [ ] 订单、送货单、原桶/袋标签、报告和发票的型号/生产者一致
- [ ] 实际生产企业地址与销售公司/仓库地址已区分并记录
- [ ] 执行标准年份、产品类别/型号、批次、生产日期、保质期和组分齐全
- [ ] 双组分A/B料配套，封口完好，无过期、结皮、结块或异常分层
- [ ] `GB/T 23445-2025`产品按新标准/型号核验；旧版资料差异已向厂家书面确认
- [ ] 产品检测/合格资料对应本型号和生产者；未把一般防水涂料误当成必须有CCC
- [ ] 防水范围、产品单位耗量、设计用量和实际进场桶数已核算并拍照
- [ ] 基层剂、节点材料、增强布、密封材料与主材系统兼容

## 节点和涂布过程

- [ ] 地漏、管根、套管、阴角、门口和稳定裂缝均按节点图处理
- [ ] 节点加强在大面覆盖前逐处检查并留近景照片
- [ ] 配料比例、搅拌时间、可使用时间按产品说明，未擅自加水/续用
- [ ] 每遍施工范围、时间、耗量和层间状态有记录
- [ ] 大面、墙角、设备后方、地漏边及门口连续覆盖，无漏刷/露底/针孔/气泡/开裂
- [ ] 实际耗量与面积及厂家规定相符；异常少料已查明，未直接覆盖
- [ ] 完工后养护达到产品允许试验条件，等待依据有记录

## 蓄水/淋水试验

- [ ] 试验前拍摄本层、楼下和相邻区域既有潮斑，已通知配合检查的人
- [ ] 排水口堵头适配且不损伤防水；门口临时挡水稳固
- [ ] 楼地面最浅处蓄水深度≥20mm，尺/水位标记和开始时间照片清晰
- [ ] 蓄水持续≥24h；开始/结束时间、房间、见证人和水位变化有记录
- [ ] 有防水要求的墙面连续淋水≥30min，范围和起止时间有记录
- [ ] 试验结束前后检查本层、楼下顶板/管根/墙角和门口外侧，无新增渗漏
- [ ] 排水时确认水流向地漏；试验异常已查因、整改并对影响范围重新完整测试
- [ ] 厕浴间饰面层完成后的第二次蓄水试验已交接给08阶段，未误认为本次已替代

## 放行与保护

- [ ] 节点、外观、用量、试验记录和整改复验资料齐全
- [ ] 防水层已保护，后续工人知道墙地防水范围和禁打孔区域
- [ ] 08贴砖人员已收到门口、地漏、墙面高度、管线图和防水交底
- [ ] 业主/指定验收联系人书面放行后才允许覆盖

结论：未通过 / 有条件通过 / 通过
