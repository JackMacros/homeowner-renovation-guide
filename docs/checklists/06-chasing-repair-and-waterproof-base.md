# 06 封槽、找平与防水基层｜现场清单

[详细说明](../stages/06-chasing-repair-and-waterproof-base.md) · [返回清单总览](index.md)

## 封槽前交接

- [ ] 05点位图、回路表、给水/排水/电气测试记录及隐蔽照片已交付
- [ ] 05异常均整改复测，业主/指定联系人书面放行封槽
- [ ] 现场已标识管线、底盒、阀门、检修口和不明/禁施工区域
- [ ] 07防水产品型号及其基层、含水、底涂和养护要求已确认
- [ ] 地漏、门口、淋浴区及后续瓷砖/地板完成面标高方案已交底

## 材料到货与样板

- [ ] 修补料/找平料/界面材料的生产者、实际工厂、型号、用途和标准可追溯
- [ ] 包装批次、生产日期、保质期、组分和储存状态已核对并拍照
- [ ] 受潮结块、过期、标签缺失或型号不符材料已隔离，未用于隐蔽处
- [ ] 产品允许基层、厚度、用水/配比、层间条件和养护方法已查说明书
- [ ] 首个典型槽口/异材交界已做样板，分层、网材和界面处理做法已确认

## 修补与找平过程

- [ ] 线管/水管/底盒已封护；槽内浮灰、松块、油污及污染物已清理
- [ ] 深槽/孔洞按材料系统分层填实，无只封表面或可见空腔
- [ ] 需要增强的部位按方案埋网，网材未浮贴、外露、褶皱或跨盖活动裂缝
- [ ] 裂缝已标记并判断；疑似结构/沉降裂缝未被普通砂浆遮盖
- [ ] 找平/找坡施工前已标记完成面基准、地漏和门口多点标高
- [ ] 湿区连续坡向地漏，门口和相邻房间无明显向外倒坡
- [ ] 砂浆未被随意加水、二次加水或超出产品规定厚度一次厚填

## 养护、检查与整改

- [ ] 养护/等待按具体产品、施工厚度和现场状态确认，无统一天数口头放行
- [ ] 墙地面无未处理的松动、成片起砂、空鼓、裂缝或孔洞
- [ ] 靠尺/塞尺实测点和最大间隙已记录，允许偏差依据已写入交底/合同
- [ ] 激光标高记录覆盖门口、地漏、淋浴区、墙边及相邻地面
- [ ] 可疑坡向经多点标高复核；清水观察（如做）已记录且不影响楼下/管线
- [ ] 不合格点已编号整改，达到条件后按原方法复验并留前后照片

## 07防水开工放行

- [ ] 基层坚实、连续、清洁，浮灰/油污/尖锐凸点已清除
- [ ] 07施工人已逐项确认基层含水、底涂、平整度及修补料兼容要求
- [ ] 管根、地漏、门口和阴阳角等节点形状与07方案一致
- [ ] 05管线未因封槽受损；如有损伤，已由对应工人修复并重新测试
- [ ] 材料标签、用料、样板、标高/坡向、整改和复验照片已归档
- [ ] 业主/指定验收联系人书面放行后才允许07防水材料开桶

结论：未通过 / 有条件通过 / 通过
