# 05 水电与给排水改造｜现场清单

[详细说明](../stages/05-mep-rough-in.md) · [返回清单总览](index.md)

## 开槽前：点位与设备接口

- [ ] 点位图标出房间、用途、编号、完成面尺寸和量尺基准
- [ ] 现场逐点模拟门扇、柜体、台面、床/电视柜及插头空间，无冲突
- [ ] 大功率设备型号/功率、供电方式及给排水接口已交电工/管工核对
- [ ] 物业、原设计或专业人员已确认可施工区域；梁柱、楼板、钢筋和公共管线未擅自开槽
- [ ] 开槽前已拍摄全屋放样照片，业主明确同意开槽

## 材料到货：逐批核对并留证

- [ ] 电线逐卷核对订单、卷盘标签和线身标识：制造商、完整型号、截面、标准、批次/日期、卷长
- [ ] 属于CCC目录的电线/电器已按准确型号、生产企业/工厂和证书状态查询；不以包装印字代替核验
- [ ] 线管、底盒、接头、断路器及插座型号、数量与清单一致，外观无裂纹、变形和缺件
- [ ] 给水管/管件标签与管身标识的生产者、工厂、规格、用途、标准、批次相符，系统及连接工具匹配
- [ ] 排水管径、管件角度、密封圈、地漏/清扫配件与已确认的路径和器具接口相符
- [ ] 错料、混批、破损、标签/文件缺失已隔离拍照；未确认前没有埋设

## 电气隐蔽：线路与配电箱

- [ ] 线管固定且未压扁，盒口有保护，管路无埋墙接头并可穿换
- [ ] 每回路两端有编号，规格变更已书面记录，配电箱标识与实际用途对应
- [ ] 保护器件参数和回路分配由电工按设备负荷/设计确认，未以加大空开处理跳闸
- [ ] 电工已记录适用的导通、绝缘、保护接地/等电位和RCD检查；记录含回路、仪表、结果、日期和操作者
- [ ] 业主未自行拆带电配电箱或操作兆欧表；异常回路未送电/封闭

## 给水隐蔽：试压和接头巡查

- [ ] 测试前写明测试边界、采用依据、压力/时间判定方法、仪表和见证人
- [ ] 测试过程中逐个巡查热熔/卡压/螺纹接口、阀门、分水器和末端，无渗漏
- [ ] 试压记录有时间、起止及过程读数、仪表信息、异常和复测结果；未通过已修复并重测
- [ ] 阀门、分水器和需维护接头可操作；隐蔽管线有编号、定位图和照片

## 排水隐蔽：坡向、通水与检修

- [ ] 排水管走向、管径、接口、支撑及接入点与图纸/现场确认一致
- [ ] 关键管段多点复核标高/坡向，无下垂、反坡、松动或结构擅改
- [ ] 每个器具口持续放水并巡查接口、末端和可见下层，无渗漏、返水或明显排水迟缓
- [ ] 地漏/器具水封、防臭、清扫口和软管防脱方案可检查、可清理
- [ ] 排水测试异常已定位整改并复测，不以局部倒水代替实际器具排放检查

## 封槽停检与放行

- [ ] 弱电线两端编号对应；约定的线序/链路测试结果已记录
- [ ] 每面墙、地面均有全景、接头近景和带尺定位照片，图纸已按实测更新
- [ ] 电气、给水、排水异常均有整改与复测闭环记录
- [ ] 线管口、底盒、给排水管口和线缆端头封堵保护，避免砂浆/垃圾进入
- [ ] 订单/发票/标签、测试表、回路表、管线图、照片和变更单已归档
- [ ] 业主或指定验收联系人书面放行后，才允许06阶段封槽并支付对应节点款

结论：未通过 / 有条件通过 / 通过
