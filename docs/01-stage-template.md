# 工序卡的阅读与编写规则

每一道工序使用相同结构，方便业主在现场快速找到需要的信息。

## 标准结构

1. **阶段目标**：完成后应得到什么结果。
2. **进场条件**：上一阶段做到什么程度才能开工。
3. **工作内容**：本阶段报价和施工应包含什么。
4. **前后工序关系**：会覆盖什么，会影响谁。
5. **常见工艺**：主流方案及各自适用条件。
6. **材料清单**：主材、辅材、规格和进场核对方式。
7. **方案利弊**：成本、工期、效果、维修性和风险。
8. **常见问题**：质量缺陷及产生原因。
9. **偷工减料信号**：业主在现场可识别的异常。
10. **开工前确认**：需要与工人书面确认的问题。
11. **过程检查**：施工中值得到场查看的节点。
12. **等待与养护**：等待目的、条件和放行依据。
13. **停检点**：未经检查不得覆盖的内容。
14. **验收重点**：最影响安全、耐久和使用的项目。
15. **检查方法**：使用什么工具、怎样操作、怎样记录。
16. **整改与复验**：不合格后如何闭环。
17. **成品保护**：下一工种如何避免破坏。
18. **资料留存**：照片、视频、数据、单据和签字。
19. **付款条件**：验收与阶段款如何关联。

## 工序放行状态

每个阶段最终只能处于以下状态之一：

- **未开始**：资料、材料或现场条件未满足；
- **施工中**：尚未达到检查条件；
- **等待中**：正在干燥、固化、养护或测试；
- **待验收**：可以检查，但尚未确认；
- **整改中**：发现问题，禁止覆盖；
- **已放行**：复验合格，可以进入下一阶段。

“工人已经做完”不等于“已放行”。

## 现场照片规则

每个隐蔽位置建议至少拍摄：

1. 能说明房间和方向的全景；
2. 能看清做法的近景；
3. 带卷尺、水平尺等尺寸参照的照片；
4. 材料包装、完整型号和生产批次；
5. 测试过程及结果；
6. 整改前后的同角度对比。

照片文件名可统一为：

`日期-阶段-房间-墙面方向-内容-序号`

例如：`2026-10-09-水电-厨房-北墙-给水管定位-01.jpg`。
